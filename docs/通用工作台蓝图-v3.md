# 通用工作台蓝图 v3 · 通用底座 + 专项适配

> 本篇把定位从"单机材料台账"提升为**多岗位办公工作台**：先把通用办公能力沉淀成可复用底座，班级材料是第一个专项业务；后续专项（社团活动、奖助评审等）在同一底座上装配。
> 业务口径沿用《工作台蓝图.md》；外部对接分级与适配器架构沿用《可选能力与通用对接蓝图.md》；表格与交互范式对照《工作台升级蓝图-v2.md》。本篇聚焦**岗位模型、分层架构、底座/专项清单与 UI 规范**。
> 状态：规划稿，未经确认不改现有可运行版本。

## 一、定位与设计主张

1. **通用与专项分离**：底座不绑死班级业务，只认通用记录模型（对象、字段、状态、动作、责任人、来源）；班级材料通过类别、模板、字段、编号规则等配置装配成专项。
2. **多岗位协作视角**：同一业务由不同岗位承担不同环节，界面、数据范围、可操作动作按岗位区分，而不是一个"管理员"包揽全部。
3. **对标成熟办公软件习惯**：信息架构、列表/审批/详情/反馈的交互贴近飞书、钉钉、Ant Design Pro；状态可见、过程可追溯、关键动作人工确认的思路参考 agent 平台。
4. **离线优先、可回退**：不启用外部能力时纯本地闭环；任何对接与 AI 失败都能回退本地，不卡死、不丢数据。

## 二、参考范式与落地映射

| 参考来源 | 范式要点 | 本工作台落地 |
|---|---|---|
| 飞书审批 | 自定义表单＋审批链，节点状态实时可见，流程记录自动归档 | 材料"经办人初审 → 管理者定稿"节点流；每个节点记录经办人与意见 |
| 钉钉组织权限 | 多层级部门、角色权限配置，通讯录准确可用 | 岗位角色 × 权限点 × 可见范围；界面按岗位过滤菜单与动作 |
| 飞书多维表格 | 字段类型、多视图、仪表盘、历史记录溯源、连接器 | 列表套件（排序/分页/密度/列设/视图）、统计看板、留痕时间线、对接适配器 |
| Ant Design Pro | 待办优先首页、ProTable 套件、抽屉详情、空态/结果页 | 岗位首页待办队列、右侧抽屉不离开列表、加载/空/无结果/失败四类状态 |
| Agent 平台（人在环） | 敏感动作前审批卡、步骤状态指示、审计轨迹可回溯、非阻塞内联卡片 | 关键动作二次确认、状态流转可见、全量留痕可追溯；AI 只出建议、人工拍板 |
| 工作台聚合 | 待办/通知/常用入口置顶 | 首页待办汇总、快捷操作、最近动态 |

## 三、分层架构

```
┌─────────────────────────────────────────────────────────┐
│ 专项业务层  材料台账 · 名单核对 · 任务跟踪 · 模板表单 ·     │
│            文件夹收集 · 审核流转 · 留痕日志                │
├─────────────────────────────────────────────────────────┤
│ 通用底座层  岗位权限 · 导航框架 · 列表套件 · 表单套件 ·     │
│            详情抽屉 · 反馈通知 · 空态/错误态 · 仓库契约 ·  │
│            配置偏好                                        │
├─────────────────────────────────────────────────────────┤
│ 对接扩展层  适配器：文件夹 / 文件 / 平台 / 网页 / AI       │
│            默认关闭 · 配置驱动 · 可回退本地                │
└─────────────────────────────────────────────────────────┘
```

- **解耦原则**：底座只提供通用模型与组件；专项差异通过配置（类别口径、模板字段、编号前缀、状态枚举、动作集合）描述，不在底座里写死班级规则。
- **仓库契约**：方法契约固定（list/add/archive/reject、logs、stats、backup/restore、roster、tasks），本地 `LocalRepository` 与将来的 `RemoteRepository` 实现同一组方法，界面与流程不随后端重写。
- **统一入库与留痕**：无论数据来自手工录入、文件夹收集、外部对接还是 AI 建议，入库与动作都走同一套仓库方法和日志留痕，并标注来源。

## 四、岗位与权限模型

### 4.1 角色分层

| 角色 | 对应岗位 | 核心职责 | 可见范围 |
|---|---|---|---|
| 经办人 | 学委 / 团支书 / 班长 / 社团干事 | 收集核对、催交、录入、初审、归拢附件 | 本组/本班材料 |
| 审核者 | 辅导员 / 班主任 / 指导老师 | 审批定稿、归档驳回、查看积压、抽查留痕、导出上报 | 管辖范围全部 |
| 汇总者 | 学院团总支 / 教务干事 / 负责人 | 跨组汇总、统计报表、口径与模板维护、备份恢复 | 全量＋配置 |
| 申请人 | 学生本人（非办公岗） | 提交本人材料、查看状态、按意见补材料 | 仅本人记录 |

### 4.2 权限点枚举

| 权限点 | 含义 | 经办人 | 审核者 | 汇总者 | 申请人 |
|---|---|:--:|:--:|:--:|:--:|
| `docs:create` | 录入材料 | ✓ | ✓ | — | ✓（本人） |
| `docs:edit` | 编辑材料 | ✓ | ✓ | — | 限本人 |
| `docs:archive` | 归档定稿 | — | ✓ | ✓ | — |
| `docs:reject` | 驳回并填原因 | 初审可退补 | ✓ | ✓ | — |
| `docs:export` | 导出台账/CSV | ✓ | ✓ | ✓ | — |
| `docs:import` | 批量导入材料（CSV 入账） | ✓ | ✓ | — | — |
| `roster:manage` | 维护名单 | ✓ | ✓ | ✓ | — |
| `task:manage` | 维护任务与截止 | ✓ | ✓ | ✓ | — |
| `template:config` | 维护模板与类别口径 | — | — | ✓ | — |
| `backup:restore` | 备份与恢复 | — | ✓ | ✓ | — |
| `logs:view` | 查看操作日志 | ✓ | ✓ | ✓ | — |
| `config:manage` | 系统设置与可选能力 | — | — | ✓ | — |

### 4.3 界面策略四档

- **隐藏**：无权限的动作与菜单不出现；
- **禁用**：存在但置灰，说明需要的角色；
- **只读**：可见不可改；
- **可操作**：完整开放。

> 边界：本地单机版的角色适配只做界面层裁剪；真正的身份认证与权限强制必须落在后端，前端不承担安全边界。

## 五、通用底座功能清单（必须搞好）

### 5.1 工作台首页
- 按岗位呈现待办队列：经办人＝未交待补＋待入账；审核者＝待审批＋积压；汇总者＝统计概览。
- 统计卡片可下钻到对应筛选台账；常用入口（提交、台账、导出备份）固定显眼位置；最近动态流。

### 5.2 全局检索与筛选
- 跨对象关键词检索；状态、类别、类型、时间、姓名/学号叠加筛选；已生效条件做成可移除标签；显示匹配条数；筛选态离开后保持。

### 5.3 列表套件
- 列头排序、分页与每页条数、行密度切换、列显隐与偏好记忆、首列冻结、行多选；加载中 / 空表 / 无结果 / 失败四类状态各有界面。

### 5.4 表单套件
- 分区分组布局；逐字段就近校验；草稿暂存，误关不丢；必填与格式规则可配置；附件字段与多附件登记。

### 5.5 详情抽屉
- 右侧滑出，左侧列表保留筛选与浏览位置；分区呈现基本信息、附件、说明、留痕时间线；底部行内快捷动作。

### 5.6 反馈与通知
- 操作 toast、批量结果汇总（成功几条/失败几条及原因）、长任务进度；错误提示说清发生了什么、数据是否保住、下一步点哪；预留通知中心位置。

### 5.7 权限与导航
- 菜单按岗位过滤；角色徽标标注当前身份与可见范围；无权限访问给说明页而非白屏。

### 5.8 设置与偏好
- 界面偏好（密度、列设）；可选能力开关（沿用 L1/L2/L3 分级）；备份恢复与数据管理入口。

### 5.9 组件与视觉规范
- 统一设计 token、8px 栅格、控件规格、状态标签、图标语言、空态引导；浅色一套完整可用，预留暗色变量层。

## 七、UI 规范要点（对齐成熟办公软件习惯）

### 7.1 布局
- 左侧导航 224px ＋ 顶部全局栏（标题、角色徽标、摘要）＋ 内容区；8px 栅格，间距成档；内容宽度自适应。
- 宽屏双栏（列表＋详情抽屉）；窄屏导航折叠横滑，表格转卡片列表。

### 7.2 色彩与字体
- 浅色一套完整 token（页面底、卡片、发丝线、主色、分级文字、语义色）；预留暗色变量层，不在本期实现。
- 标题/正文/辅助/弱化四档字号；编号、学号、统计数字用等宽数字。

### 7.3 控件规格
- 主按钮唯一突出；默认按钮白底发丝边；输入/下拉 36px 高、8px 圆角；聚焦主色边＋浅光环；危险动作用红色语义。
- 表格行分隔线、表头次要色、行悬停浅底；状态标签小方角、色点＋文字。

### 7.4 反馈与可达性
- 破坏性动作点名确认；空态带下一步指引；可点控件有可见焦点环，支持键盘 Tab 与回车触发。
- 图标用内联线性 SVG，不使用 emoji 装饰。

## 八、现状对照与缺口归类

### 8.1 底座层
- **已有**：导航框架、基础列表、搜索与叠加筛选、条件标签与计数、筛选保持、排序/分页/密度/列显隐/首列冻结（网页版）、详情抽屉、表单校验与草稿、toast、备份恢复、偏好记忆、空态引导。
- **缺口**：多岗位角色与权限点模型；初审—定稿审批节点；按岗位的首页待办；跨对象全局检索；通知中心；桌面端列表套件对齐网页；撤销与回收站；命名常用视图；暗色主题；移动端卡片化。

### 8.2 专项层
- **已有**：模板与编号前缀、名单核对、任务截止跟踪、文件夹收集比对入账、附件登记、审核备注、操作留痕。
- **缺口**：文件名/文档内容自动认人；附件真实落地与可打开；Excel 导入导出；催交记录闭环；材料齐套与合规检查；模板/类别可配置。

### 8.3 对接层
- **缺口**：通用适配器落地；外部平台只读→写入试点；AI 辅助（分类建议、齐全度检查、重复识别、草稿、检索问答），人在环确认；消息通知外发。

## 九、分阶段路线

### P0 · 底座与岗位模型（本地闭环内）
1. 落地岗位枚举与权限点表，界面按岗位隐藏/禁用/只读/可操作。
2. 按岗位拆首页待办队列与默认筛选。
3. 拆分初审—定稿审批节点，队列与留痕分别记人、记意见。
4. 桌面端补齐排序/分页/多选批量，与网页版列表套件对齐。

### P1 · 专项补全与两端对齐
1. 文件夹/入账时按文件名匹配名单学号姓名，自动带出提交人。
2. 附件集中落地，备份/导出携带附件清单。
3. Excel 导入导出；驳回/移除的限时撤销与回收站；命名常用视图；催交清单导出。

### P2 · 对接与 AI（默认关闭，可回退）
1. 适配器框架落地，先做本地文件与文件夹适配器；选一个在用平台做只读试点。
2. AI 辅助从分类建议切入，扩齐全度检查、重复识别、草稿；建议入留痕，关键动作人工确认。

### P3 · 多人协作（需另立架构评估）
1. 后端服务、账号体系、云端附件、跨端一致；手机端查看；学期材料打包归档与审计导出。

## 十、边界与不承诺

- 单机本地版不保证多人实时一致；多人共享、跨端同步必须走后端方案。
- 附件当前仅记录文件名/路径，文件本体未落盘；换设备后附件打不开。
- 前端角色适配不等于安全权限；真正身份分级控制依赖后端。
- 外部平台对接、网页识别、AI 能力默认不启用；启用前明示数据流向，可随时回退本地。
- 自检覆盖代码路径与常见边界，不等于所有环境、数据组合零缺陷；不同分辨率、字体缩放、长时间运行仍需实机观察。
