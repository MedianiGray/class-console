## 三、为什么 TTS 先接系统语音，而不是这十个库

1. **包体**：桌面便携包已压到 21.2MB，加 PyTorch 就是 +2GB 起，等于放弃便携。
2. **离线**：材料文件名、学生姓名、催交话术都属于本机数据，gTTS / 云端 TTS 要上传文本，这条红线不能破。
3. **零安装**：Windows 自带 SAPI，`tts.py` 只调系统组件，不引入第三方包，符合"不装工具、做进仓库"。
4. **可回退**：读不出来就返回原因（"未找到中文语音"），不阻断任何业务流程。

## 四、v0.28.2 实际落地的东西

- `tts.py`：探测系统语音（优先 `zh-*`）、朗读、停止、状态句；朗读跑在独立进程，可随时杀；文本写临时文件传参，避开命令行引号转义。
- 「服务留痕」底栏加 **朗读内容**：读"类型 + 学生 + 类别 + 完整话术"，再点一次停止；没选中时禁用。
- 「材料台账」右栏详情头部加 **朗读**：读当前这份材料的信息、审批节点与最近操作（截前 800 字）。
- 回归：`tests/selftest.py` 第 50 组（探测口径、拒空、非朗读态）；`tests/gui_smoke.py` 增"朗读入口存在与启用态"断言，但**不在测试里发声**。
- 边界：首句约 1–2 秒预热（PowerShell + 语音引擎初始化）；只朗读，不改数据、不写日志、不发消息。
