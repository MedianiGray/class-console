# 办公工作台总图 v2.0

> 定位：**先为师生服务，再长成项目型办公工作台。** 学生少跑一趟，班委少熬一夜，老师少等一轮；音频、比赛、产品等专业项目，按同一套项目骨架逐步接入。
>
> 状态：路线总图。自本文件起，版本排期以这里为准；旧蓝图保留为历史稿，不再各自排期。
> 当前应用基线：桌面 v0.30.1 / 网页 v0.28.1。

---

## 0. 三条底线

1. **先服务，后炫技。** 门户、导航、功能取舍都先回答“师生少做什么”，再回答“技术多强”。
2. **一个版本一个闭环。** 每个版本只打通一条可验收的路径，验收不过不进下一版；不再从 0.3x 直接跳 1.0。
3. **专业能力分四档。** 原生、集成、引导、外链；每个能力必须过六道门：输入可识别、参数可解释、执行可取消、输出可质检、产物有清单/哈希、全程可留痕/可撤销。

---

## 1. 产品结构

```
工作台外壳
├─ 班级材料专项（当前主力，已可用）
│  提交 / 收集 / 审核 / 归档 / 矩阵 / 催交 / 证据包 / 交接包
├─ 项目工作台（下一步）
│  项目 / 阶段 / 交付物 / 资产 / 执行记录 / 质量门 / 项目包
├─ 专业工具台（按需接入）
│  媒体转码 / 文档转换 / OCR / 数据清洗 / 打包校验
└─ 治理与自动化
   版本 / 评审 / 权限 / 审计 / 队列 / 文件夹监听 / 定时任务
```

班级材料不是整个产品，而是第一个项目模板。项目工作台也不是另一个软件，而是把材料、任务、资产、交付物挂到同一个“事”上。

---

## 2. 服务对象

| 对象 | 最需要工作台做什么 | 当前能给 | 下一步 |
| --- | --- | --- | --- |
| 学生 | 不装软件就能提交；知道自己缺什么、到哪一步 | 网页提交、状态查看、缺项提示 | 更短的提交入口、进度查询 |
| 班委 | 收得齐、催得准、归得对、交得出去 | 收集、台账、矩阵、催交、归档、证据包 | 项目事项、批量工具、交差产物 |
| 教师 / 辅导员 | 看全局、抽查留痕、收上报材料 | 岗位视角、日志、证据包、交接包 | 汇总报表、评审门、项目进度 |
| 项目负责人 | 比赛、产品、活动、媒体项目不散 | 任务与材料 | 项目模板、交付物、质量门、项目包 |

## 3. 十二个工作域

| 工作域 | 典型项目 | 必须配的能力 | 交付物 |
| --- | --- | --- | --- |
| 知识文档 | 报告、论文、制度、合同、翻译 | 写作、排版、转换、OCR、比对、引用、版本 | DOCX/PDF/PPT/MD + 源文件 |
| 数据与洞察 | 调研、统计、报表、预测 | 导入、清洗、统计、可视化、报告、数据治理 | XLSX/CSV/图表/报告 |
| 媒体内容 | 音频转码、视频压缩、字幕、配音 | 转码、剪辑、合成、字幕、TTS、降噪、批处理 | 媒体包 + 清单 + 哈希 |
| 软件与系统 | 网站、小程序、自动化、运维 | 需求、架构、编码、测试、构建、部署、监控 | 仓库/安装包/部署说明/测试报告 |
| 实物产品 | 样品、BOM、包装、试制 | PRD、BOM、成本、供应商、原型、测试、认证 | 产品包/样品/说明书/认证 |
| 赛事与评审 | 竞赛报名、作品、答辩 | 日历、报名、评审标准、版本、答辩、提交校验 | 报名包/作品包/答辩包/复盘包 |
| 活动与运营 | 班会、团日、志愿、路演 | 策划、审批、通知、签到、现场、宣传、结算 | 活动包/新闻稿/总结/结算 |
| 组织与人事 | 名单、角色、培训、考核、交接 | 名单、权限、任务、培训、考核、交接 | 名单/制度/培训包/交接包 |
| 商务与财务 | 预算、询价、合同、发票、报销 | 预算、比价、合同、发票、报销、成本 | 预算表/合同/结算包 |
| 合规与安全 | 等保、版权、隐私、审计 | 清单、对照、取证、整改、脱敏、审计 | 合规包/审计报告/证据包 |
| 科研课题 | 文献、实验、论文、申报 | 文献、选题、实验记录、数据、投稿、结题 | 申报书/论文/数据包/结题 |
| 教学培训 | 课程、教案、作业、测评 | 课程设计、教案、作业、测评、反馈、证书 | 课程包/教案/题库/证书 |

音频只是“媒体内容”里的一格；比赛只是“赛事与评审”里的一格；产品跨越“实物产品 / 软件系统 / 知识文档”三格。

## 4. 九类帮助

| 帮助 | 做什么 | 例子 |
| --- | --- | --- |
| 接入 | 把外部东西收进来 | 文件夹、表单、链接、OCR、ASR、API |
| 规范 | 统一格式、编码、命名、字段 | 音频转码、文件改名、表格口径 |
| 生成 | 出初稿、做素材、合成内容 | 转写、字幕、PPT、PRD、说明书 |
| 分析 | 提取、比对、统计、估算 | 输出探测、评审标准对照、成本估算 |
| 编排 | 排阶段、任务、依赖、负责人 | 转码队列、比赛里程碑、产品评审门 |
| 质检 | 用规则和清单卡质量 | 编码/时长检查、格式校验、测试报告 |
| 交付 | 打包、校验、发布、回执 | 音频包、报名包、发布包、路演包 |
| 治理 | 版本、权限、日志、证据、交接 | 版本冻结、评审意见、提交凭证 |
| 复用 | 复盘、模板、知识库 | 转码预设、比赛模板、项目复盘 |

## 5. 版本阶梯

> 规则：一个版本只做一条闭环；验收通过才进下一版。版本号连续推进，不跨段。

| 版本 | 单一闭环 | 验收 | 本版不做 |
| --- | --- | --- | --- |
| 门户改版（站点，不占应用版本号） | 为师生服务的门户：角色入口、能力地图、路线、边界 | 学生/班委/教师都能在 30 秒内找到自己的入口；未上线能力明确标注 | 不改桌面主程序 |
| v0.31 项目底座 | 项目 / 阶段 / 交付物 / 资产 / 执行记录 / 质量门 | 新建一个项目，挂 3 个交付物，看到完成率与缺项；材料模板迁移为第一个项目模板 | 不做媒体工具、不做多人协作 |
| v0.32 媒体样板 | 音频批量转码：输入→预检→转码→质检→交付 | 20 个音频一次跑完；每个输入有输出；时长/编码符合；清单+哈希；源文件未动 | 不做视频剪辑、不做复杂特效 |
| v0.33 文档工具 | PDF 拆分合并、OCR、Office/PDF 转换、图片批处理 | 每类工具过六道门；失败可重试；产物有清单 | 不做完整 Office 编辑器 |
| v0.34 赛事模板 | 竞赛日历、报名清单、评审标准矩阵、提交校验、答辩包 | 一次真实比赛从报名到提交跑通；格式/大小/命名校验通过 | 不爬赛事官网 |
| v0.35 产品模板 | PRD、BOM/架构、原型、测试、发布包、路演 | 一个产品项目从立项到发布包跑通；评审门有记录 | 不做 CAD/IDE 内置 |
| v0.36 数据/活动模板 | 数据清洗图表报告；活动策划签到总结 | 各跑一个真实项目；产物可交付 | 不做在线报名后端 |
| v0.37 自动化 | 文件夹监听、批处理队列、定时任务、规则 | 一条规则无人值守跑一周无错；可停可回滚 | 不做云端调度 |
| v0.38 治理 | 版本、评审、权限、审计、项目包 | 一个项目可导出/导入；评审意见与版本可追溯 | 不做账号后端 |
| v0.39 真实验收 | 音频、比赛、产品、班级材料四类项目 | 四类各一个真实项目从头到尾；20 项人工走查签字 | 不扩新域 |
| v1.0 稳定版 | 安装、性能、文档、发布门禁、交接 | 干净环境可复现；失败有兜底；换届可接手 | 不承诺多人实时 |

## 6. 现在的位置

- 0.30.1 完成了“材料专项 + 通用外壳 + 能力中心收口”。
- 十二个工作域里，只有“知识文档 + 组织人事”的材料一条线做到深水区；项目层、资产层、工具层、自动化层还没开始。
- 下一步是 v0.31 项目底座；门户改版先做，是为了把“为师生服务”的卖点说清楚，不占应用版本号。

---

## 7. 不做清单

- 不做全能 Office / Adobe 替代品；专业深水区走集成或外链。
- 不做账号、多人实时协作、云端收集，直到后端方案单独立项。
- 不做平台爬取、自动群发、自动删除原件。
- 不做没有输入、预览、质检、产物的“假功能卡”。
- 不跳过版本，不把三个版本的功能塞进一个版本。
