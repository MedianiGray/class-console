# 班级操作台 · 蓝图全景展开 v1.1

> 这份文件回答三个问题：**现在有什么、为什么还不好用、AI 到底放哪里。**
> 《最佳形态蓝图 v1.0》定目标，本文件负责把目标展开成结构、功能账和版本排期。
> 当前基线：网页 v0.25.0 / 桌面 v0.23.0。

---

## 0. 先给结论

1. **现在不是“功能为零”，而是“功能长歪了”**：不少能力已经做出来，但藏在二级菜单、只做半程、彼此不接力，所以用起来仍然像缺很多。
2. **AI 已经装上了，位置也先摆正了**：网页版 v0.20 起有 AI 助手；v0.25 把主入口提到顶栏「AI 副驾」，材料详情里四个就地建议，完整聊天页降为高级兜底。桌面端仍未接 AI。
3. **AI 的正确位置不是第六个导航页，而是三个物件之上的“副驾层”**：材料、名单、任务选中谁，就在右栏给谁出建议；流程走到哪一步，就在哪一步给草稿。完整对话页保留，但降为高级兜底。

---

## 1. 整体结构：三层，不是一堆卡片

```
┌──────────────────────────────────────────────────────────────┐
│ 第一层：骨架（东西在哪里）                                    │
│   材料档案室  ←  台账 + 文件室                                │
│   完成矩阵    ←  人 × 材料类别                                │
│   事务时间线  ←  提交 / 审核 / 归档 / 催交                    │
├──────────────────────────────────────────────────────────────┤
│ 第二层：流程（事怎么办）                                      │
│   早上打开 → 收材料 → 审材料 → 归档 → 催交 → 交差             │
├──────────────────────────────────────────────────────────────┤
│ 第三层：副驾（AI 在哪里帮忙）                                 │
│   右栏建议 → 流程节点建议 → 命令面板 → 高级对话页             │
└──────────────────────────────────────────────────────────────┘
```

**判断顺序**：先有骨架，再有流程，最后才是副驾。AI 不能替代台账、矩阵、时间线；它只能让这三件事更快被看懂、被写出来、被交接。

## 2. 一屏解剖：五个区 + 一个副驾位

```
┌──────────────────────── 顶栏 56 ────────────────────────┐
│ 品牌    ⌘K 搜索 / 命令      ✦ AI 副驾    提醒 3   身份 ▾   ⚙ │
├ 侧栏 64/212 ┬──── 主工作区 ─────────────┬ 上下文栏 320 ┤
│ 材料流程     │ 页头：标题 + 角色 + 视图切换 │ 概览 / 文件    │
│  概览        │                            │ 留痕 / AI 建议 │
│  材料台账    │ 内容：表格 / 矩阵 / 文件室  │ 操作 / 备注    │
│  文件室      │                            │              │
│ 协同跟进     │                            │              │
│  完成矩阵    │                            │              │
│  任务时间线  │                            │              │
│  操作日志    │                            │              │
├──────────────┴────────────────────────────┴──────────────┤
│ 状态栏 26：本地模式 · 材料 7 · 未交 2 · 索引一致          │
└──────────────────────────────────────────────────────────┘
```

### 2.1 五个区的职责

| 区 | 只做什么 | 不做什么 |
| --- | --- | --- |
| 顶栏 | 身份、搜索/命令、AI 副驾入口、提醒、设置 | 不放“提交材料”这类业务按钮 |
| 侧栏 | 导航与分组，可收成图标条 | 不放筛选器和开关 |
| 主工作区 | 当前唯一任务；一屏一个实心主按钮 | 不铺第二套导航 |
| 上下文栏 | 选中对象的全部信息、操作、AI 建议 | 不承担全局导航 |
| 状态栏 | 数据规模、索引状态、快捷键提示 | 不放操作按钮 |

**关键改动**：右栏从“详情抽屉”升级成“上下文栏”。AI 建议不是另开一页，而是右栏的第四个页签，和概览、文件、留痕并列。

## 3. 三个物件，AI 分别怎么接

| 物件 | 主视图 | AI 副驾做什么 | 绝不做什么 |
| --- | --- | --- | --- |
| 材料 Doc | 台账 + 文件室 | 缺项检查、驳回原因草稿、归档命名建议、情况说明、证据包目录说明 | 不自动改状态、不自动归档、不自动发消息 |
| 人 Student | 完成矩阵 | 汇总缺哪几类、生成不点名催交话术、解释免交/延期口径 | 不公开点名、不排名、不替人下判断 |
| 事 Event | 时间线 | 把流转链写成一段可交差说明、提取异常节点、生成复盘提纲 | 不编造未发生的提交或审核 |

## 4. 功能全景账

> 口径：**有** = 已可用；**半** = 有入口但只做半程或藏得深；**缺** = 还没做。
> 这张表不是为了证明“做得多”，而是为了看出“哪里断”。

### 4.1 入口与外壳

| 能力 | 现状 | 缺口 / 下一步 |
| --- | --- | --- |
| 工作台概览 | 有，Bento 7 卡 | 卡偏多；下一步收成“三个问题 + 一个主按钮 + 一条下一步” |
| 材料台账 | 有，搜索/筛选/排序/分页/批量 | 详情仍是抽屉，不是常驻上下文栏 |
| 提交材料 | 有，模板/校验/附件记录 | 提交后下一步引导还不够强 |
| 全局搜索 / 命令面板 | 有，可搜材料/人/任务，`>` 执行动作 | 文件全文与文件室搜索只在桌面 |
| 提醒中心 | 有，按岗位汇总待审/驳回/临期/未交 | 提醒不能一键转成任务或催交 |
| 移动 / PWA | 有，可安装、断网重载 | 首次打开 SW 未接管时离线要等一次重载；无“新版本可用”提示 |
| 双端分工 | 现状双端都完整 | 与蓝图“网页同学侧、桌面管理台”冲突，需要拍板 |

### 4.2 材料流转

| 能力 | 现状 | 缺口 / 下一步 |
| --- | --- | --- |
| 审核 / 驳回 | 有，可填原因，留痕 | 审核动作已闭环，但右栏没有 AI 核对建议 |
| 批量归档 / 驳回 | 有，多选与批量条 | 批量结果可重试，失败原因可再收 |
| 归档规则 | 有，类别映射/命名模板/重名加序号 | 归档前路径预览已有，规则解释可更直白 |
| 文件室 | 桌面有；网页没有 | 网页按定位可不做；若要做，只做“查文件在哪”的轻量入口 |
| 模板字段 | 有，可视化配置 | 模板与提交表单的“缺什么”提示还可加强 |
| CSV 导入导出 | 有 | 导入失败逐行反馈可再细化 |
| 证据包 | 有，ZIP + README + 索引/日志/文件树 | 可加一份“AI 生成的目录说明草稿”，但必须人工确认 |

### 4.3 人与催交

| 能力 | 现状 | 缺口 / 下一步 |
| --- | --- | --- |

| 届别交接包 | 有，台账/索引/日志/设置 | 交接包导入后的差异预览可再清楚 |

| 能力 | 现状 | 缺口 / 下一步 |

## 5. AI 模块落位（定稿方案）

### 5.1 一句话

**AI 不是第四个物件，是三个物件上的副驾层；入口在顶栏，主战场在右栏，完整对话页退到高级兜底。**

### 5.2 四个落点

```
① 顶栏 ✦ AI 副驾
   └─ 点开右栏 AI 面板，不跳页；Ctrl+K 也能唤起（v0.25 已实现）

② 右栏「AI 建议」页签
   ├─ 选中材料：缺什么 / 驳回原因 / 归档命名 / 情况说明（v0.25 已实现，落在详情抽屉）
   ├─ 选中人：缺哪几类 / 催交话术 / 免交解释（待 v0.26）
   └─ 选中任务：拆步骤 / 截止提醒 / 复盘提纲（待 v0.26）

③ 流程节点建议条
   ├─ 收材料扫描：新增 3 / 修改 1 / 删除 0 的人话摘要（待 v0.26）
   ├─ 批量审核：同类同态的核对清单（待 v0.26）
   ├─ 催交：从矩阵直接生成不点名话术（待 v0.26）
   └─ 证据包：生成目录说明草稿，人工确认后放入 ZIP（待 v0.26）

④ 高级对话页（保留现有 AI 助手）
   └─ 复杂任务、模型配置、API Key、完整对话；已保留在「更多 → 智能辅助」
```

### 5.3 三条硬边界

1. **只读上下文，不自动写**：AI 不直接改台账、不改状态、不发消息、不归档；所有动作要人点第二次。
2. **默认本地，API 明示**：网页默认本地模型；切 API 时明确提示“上下文会离开设备”。桌面 AI 默认关，未配置就走本地规则。
3. **生成留痕，但不污染业务日志**：AI 生成记录单独标注 `src=AI`，和提交/审核/归档日志分开筛选。

### 5.4 桌面端怎么装

- **不搬 WebGPU**：Tk 桌面不跑本地大模型，先接 OpenAI 兼容 API，默认关闭。
- **从分类建议切入**：收材料/拖入文件时，AI 只给“建议类别 + 置信度 + 理由”，人工确认后才入账。
- **失败回退**：未配置、断网、额度不足时，自动回退本地规则，不阻断主流程。
- **入口**：桌面「更多功能 → 智能辅助 → AI 建议」，不硬塞一个空聊天页。

## 6. 版本排期：AI 与功能补齐同版推进

> 用户判断是对的：不要等 v1.0 收口完再上 AI。AI 副驾和可用性修补应该同一版做，边装边用。

### v0.25「AI 副驾 + 首屏可用性」（已交付 2026-11-26）

- 顶栏加 `✦ AI 副驾`，点开右栏建议面板；材料详情加四个就地建议。
- 概览从 7 卡收到“三个问题 + 一个主按钮 + 一条下一步”，移除指标与类别卡。
- 顶栏收掉「提交材料」业务按钮；首屏只保留一个实心主按钮。
- 保留完整 AI 助手页，入口仍在「更多 → 智能辅助」，不删能力。

**验收**：选中一条材料，右栏一次点击能生成“缺项 + 驳回草稿”；不跳页、不改台账、日志可见。已按 v0.25 实现并实测。

### v0.26「功能补齐 + 混合流程」

- 收材料扫描：三行摘要 + 展开明细 + 入账即归位。
- 矩阵：点格直接建任务/生成催交话术；免交/延期就地解释。
- 全局搜索：材料/人/任务/文件（桌面）统一入口；文件室只做“文件在哪”。
- 材料详情从抽屉升级为常驻上下文栏；窄屏变浮层。
- 桌面 AI 建议（API-only，默认关，分类建议先行）。
- PWA 补“新版本可用，是否刷新”提示。

**验收**：找任意材料/人/文件 ≤2 个动作；矩阵格到催交话术 ≤2 次点击；AI 建议都能落到一个可复制结果。

### v1.0「静默版收口」

- 桌面性能：台账增量渲染 ≤100ms、源码启动 ≤1s、EXE 启动 ≤1s（或写明例外与下一轮）。
- 安装包与首启说明、SHA256、tag/Release、全量回归、人工走查签字。
- 文档口径统一：所有“当前版本/已实现/未实现”一次对齐。
- Bento/PWA 冻结，不再扩新卡片。

## 7. 验收尺（加到原蓝图第 10 节）

1. 单条材料从选中到归档 ≤3 次点击、≤20 秒。
2. 找任意材料/人/文件 ≤2 个动作。
3. 每日巡检（待审 + 未交 + 逾期）≤2 分钟。
4. 归档索引与磁盘文件一致率 100%，无孤儿文件。
5. 任意一屏只有一个视觉重点，去掉任意一张卡片不破版。
6. **AI 建议从选中对象到出草稿 ≤1 次点击；不跳页、不改数据、日志可查。**
7. **不装 AI 也能走完全流程；关掉 AI 后主流程零阻断。**
