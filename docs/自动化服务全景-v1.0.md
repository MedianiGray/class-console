# 自动化服务全景 v1.0

> 定位：把班级材料工作里「重复、易错、费眼」的部分交给程序，人只做判断与确认。
>
> 原则：自动化是**可撤销的助手**，不是黑箱代理人。

## 一、服务分级（先定权责，再谈功能）

| 级别 | 行为 | 默认 | 适用 |
| --- | --- | --- | --- |
| L0 观察 | 只扫描、只报告差异，不动文件 | 常开 | 文件夹监听、完整性检查 |
| L1 建议 | 给出「识别结果 + 目标路径 + 动作」，等人确认 | **默认级别** | 收材料、归类、命名 |
| L2 一键 | 预览 dry-run 后整批执行，可撤销 | 手动触发 | 批量归位、批量重命名、去重 |
| L3 规则 | 满足条件自动执行，但逐条留日志、可回滚 | 逐条开启 | 固定命名、固定归档、索引修复 |

四条硬约束：
1. **不删除原件**：默认复制；「移动」只在用户勾选并二次确认后执行。
2. **不覆盖同名**：同名不同内容加版本号，同名同内容跳过。
3. **不猜没把握的字段**：低置信度只进「待确认」，不自动填。
4. **不出归档根目录**：所有写操作限定在用户选定的根目录内。

## 三、规则引擎（自动化的心脏）

一条规则 = **触发 + 条件 + 动作 + 冲突策略**，用 JSON 存，不写代码。

示例：
```json
{
  "name": "奖助材料自动归位",
  "trigger": "file_detected",
  "when": {
    "filename_contains": ["助学金", "评议", "困难认定"],
    "sid_in_roster": true
  },
  "actions": [
    {"type": "set_category", "value": "奖助材料"},
    {"type": "rename", "template": "{编号}_{材料名}"},
    {"type": "place", "path": "奖助材料/{学号}-{姓名}"},
    {"type": "log", "level": "info"}
  ],
  "conflict": "version",
  "level": "L1"
}
```

规则中心要有：规则列表、作用范围、上次运行、成功率、开关、试运行、运行历史、撤销入口。
**默认全部 L1**；只有用户明确把某条升到 L3，才会无人值守执行，且每次仍写日志。

## 四、冲突与失败处理

| 情况 | 策略 |
| --- | --- |
| 同名同哈希 | 跳过，记「已存在」 |
| 同名不同哈希 | 加 `_v2`，旧版进历史，不覆盖 |
| 目标目录无索引记录 | 标「待确认」，不自动登记 |
| 源文件被占用 | 跳过并提示「关闭后重试」，不中断整批 |
| 磁盘空间不足 | preflight 直接中止，列出所需空间 |
| 路径过长/非法字符 | 自动截断并替换，预览可见 |
| 归档中途失败 | 已成功项保留，失败项单独重试；批次可撤销 |

## 五、最好的模样（使用现场）

**早上打开**
昨天新收的 12 个文件已经扫完：9 个高置信度，按「奖助材料/250201-覃祖悦」归好；3 个低置信度进入「待确认」，每个都写着「为什么这样判断」。顶部一条：`已整理 9 · 待确认 3 · 撤销`。

**收一份材料**
把文件拖进窗口 → 识别类别、学号、姓名 → 右侧预览目标路径 → 确认 → 复制、命名、写索引、记日志，一步完成。

**批量整理**
选 20 个文件 → 试运行列出「将改名 14、将归位 18、跳过重复 2」→ 执行 → 结果逐条可点 → 不满意整批撤销。

**学期末**
一键出「证据包」：材料清单、归档索引、操作日志、文件树、缺失清单；评审方解压就能看懂。

**换届**
导出「届别档案包」，新学委导入后十分钟接手；旧学委退出，公共记忆留在班里。

## 六、版本路线

### v0.15 整理版
- 规则引擎 + 试运行 + 撤销 journal + 命名模板 + 冲突策略 + 哈希去重 + 索引校验。
- 验收：20 个文件批量整理一次完成；撤销后磁盘与台账回到操作前；零原件丢失。

### v0.16 识别版
- 文件名解析、PDF/DOCX 文本提取、名单匹配、字段预填、待确认队列、质量检查。
- 验收：高置信度识别准确率 ≥95%；低置信度不自动填；错误可在待确认队列改正。

### v0.17 审计版
- 证据包、完整性检查、恢复预览、日志筛选。
- 验收：证据包脱离软件可读；索引不一致能被发现并修复。

### v0.18 服务版
- 完成矩阵、催交话术、回执 / 免交 / 延期、服务留痕、届别交接包。
- 验收：矩阵与台账数字一致；同一学生 24 小时不重复催；交接后新环境可继续工作。

### v0.19 文件室
- 目录树、文件列表与预览、缺失文件反查、拖入登记。
- 验收：找任意材料对应文件 ≤2 个动作；缺失文件能定位到责任人。
- 状态：0.19.0 已落地（桌面版），缩略图走 Windows Shell，登记只复制不移动。

### v1.0 静默版
- 周期任务、滚动备份、恢复预览、存储清理、性能与首次引导。
- 验收：冷启动 ≤1s；1000 文件增量扫描 ≤5s；无人值守规则运行一周无错。

## 七、不做与边界

- 不做云同步、账号、多人实时协作；自动化只在本机。
- 不自动删除任何原件；不接管归档根目录以外的文件。
- 不自动发送微信/短信；只生成话术与回执入口。
- 不做无置信度的「猜分类」；不把低把握结果写成事实。
- 不引入 AI 生成内容；识别只用文件名、文本关键词与名单比对。
