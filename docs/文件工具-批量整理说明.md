# 文件工具：批量重命名 / 格式转换 / 按类别归位（桌面端 v0.28.0）

文件室顶栏的「批量工具」是这三件事的唯一入口。打开时：**有选中就只处理选中的文件**，没选中就处理当前目录（全库搜索结果则为全部命中）。

## 一、三条路各自能做什么

### 1. 批量重命名

| 项 | 说明 |
| --- | --- |
| 前缀 / 后缀 | 直接拼在原名前后；支持三个占位：`{date}`（当天日期 20261126）、`{name}`（原主干名）、`{n}`（本批第几个） |
| 加序号 | 起始（默认 1）、步长（默认 1）、位数（默认 2 位，最多 6 位）、位置（末尾 / 开头 / 只用序号） |
| 正则替换 | 作用在**去掉扩展名的主干**上，例如 `IMG_(\d+)` → `合影$1`；写错正则会在预览里逐条报错，不会执行 |
| 排序 | 按文件名（默认）或按修改时间，决定序号跟着谁走 |
| 扩展名 | 永远原样保留，规则不碰后缀 |

改错了可以点「撤销上次改名」整体撤回（同一窗口保留最近一次成功记录）。

### 2. 图片格式转换

- 目标格式：JPEG / PNG / WEBP；质量三档：高 92 / 标准 88 / 紧凑 80（只对 JPEG / WEBP 生效，PNG 走无损）。
- 结果写回**同一目录**，文件名沿用主干、只换扩展名；已有同名的自动加 `-2`，不覆盖。
- 「保留原件」默认勾选。取消勾选时，**新文件写成功之后**才删原件；中途失败不动原件。
- 只接受图片扩展名；不是图片的、已经是目标格式的都标「跳过」并写原因。

### 3. 按类别归位

- 依据台账里这条材料登记的类别，把文件移进「归档根 / 类别 /」。
- 台账里查不到的文件**原样跳过**（提示「先登记再归位」），不会猜类别、不会乱放。
- 文件名冲突自动加序号；已经在类别目录里的标跳过。

## 二、共同的安全规则

1. **只动归档根内的文件**：根外路径（哪怕是你盘里的其它目录）一律拒绝并写明原因。
2. **先预览后执行**：预览只算名字与去向，不落盘；状态列分「待执行 / 跳过（原因）/ 有问题（原因）」。
3. **同名不覆盖**：所有写入路径都走唯一化，冲突在预览里就标出来。
4. **改名两阶段**：先统一改成临时名、再改到目标名，`a→b`、`b→a` 这类互换不会互相踩掉。
5. **台账跟着走**：改名 / 归位成功后会同步台账的归档路径（写入一个「归位」节点），并重写 `_归档索引.csv`，文件室不会立刻提示「索引待修」。
6. **动作留痕**：重命名、格式转换、按类别归位、撤销改名都会写进操作日志（动作 + 数量 + 角色）。
7. **权限**：批量工具需要归档权限，当前「申请人」岗位看不到可用入口。

## 三、边界（说清楚不做什么）

- 不做目录改名、不做删除、不做全文批量替换（只能换文件名）。
- 不做「按内容猜类别」：归位类别只读台账，台账没有就不动。
- 不做后台常驻监听与定时整理，整理是手动发起的一次动作。
- 不处理归档根之外的文件，也不处理 `_归档索引.csv`。

## 四、怎么复现测试

```bash
python3 tests/selftest.py        # 49 组，含 46–49 文件工具断言
python3 tests/gui_smoke.py       # 含「批量文件工具入口 / 三页预览」
```

打包时注意：`tools/build_onefile.py` 与 `tools/build_portable.py` 的 hidden-import 已带 `ui_filetools`、`filetools`，漏掉会出现「程序能开、点批量工具报缺模块」。
