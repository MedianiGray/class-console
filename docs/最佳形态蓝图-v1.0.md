# 班级材料操作台 · 最佳形态蓝图 v1.0

> 一句话：把「找材料、催材料、交差」三件事，压到三次点击以内。
>
> 这份蓝图描述的是**目标态**，不是当前版本说明。当前 v0.27.1 已实现的部分在文末单列。

## 0. 终局判断

**它最终应该是什么**
- 一间**班级材料档案室**：材料有位置、有索引、有留痕，脱离软件也能找到文件。
- 一张**完成矩阵**：谁交了、谁没交、缺哪一类，一眼看完，不用数。
- 一条**事务时间线**：提交、审核、归档、驳回、催交，按时间可回放。

**它最终不应该是什么**
- 不是卡片越多越好的仪表盘；卡片只用于并列信息，不做页面骨架。
- 不是弹窗套弹窗的表单系统；除破坏性确认和设置，一律就地展开。
- 不是云端协作平台；不引入账号、租户、实时同步。
- 不是以 AI 生成为主干的产品；骨架仍然是规则与索引，AI 只做副驾、只出草稿，不替人执行。

## 0.1 服务本心：效率之下还有一层

上面所有布局与流程，回答的是「事怎么办得快」。但服务不是运营，本心也不止于省时间。
如果一套工具让同学感到被追赶、被排名、被公开标记，它越高效，越背离本心。

三条不可让渡的立场：
1. **工具替人记事，不替人评判。** 状态描述的是材料，不定义人。
2. **数据属于班级，不属于个人。** 可导出、可交接、可销毁。
3. **服务在不需要时消失。** 最好的状态是没人感到它的存在。

落到具体规则：
- **默认隐私分级**：管理者看全局，同学只看自己；公开视图只出聚合完成率，不出个人未交名单。
- **语言去评判**：用「待补 / 已交 / 免交 / 延期」，不把「未交」贴在人身上；催交说「这项还差你一份」，不说「你怎么还没交」。
- **留出免交与延期**：转学、免修、校外已交，一键登记，避免无意义追赶。
- **催交不公开点名、不自动群发**：同一人 24 小时只提醒一次，并给「我已提交 / 我在校外交」的回执入口。
- **换届可交接**：一键导出「届别档案包」（台账 / 索引 / 日志 / 设置），新学委导入后十分钟接手；旧人退出，不带走公共记忆。
- **服务留痕**：除材料日志外，记「帮谁补了什么、什么时候解决」，让服务可被看见，也可被审计。
- **故障不让人背锅**：归档失败、文件缺失时给出明确恢复路径，系统问题不转化为对同学的评价。

本心验收尺（与效率尺并列）：
1. 最沉默、最拖延的那个人，会不会因为这套工具被公开羞辱？
2. 换一届学委，能不能不靠前任记忆接手？
3. 同学能不能不装软件、不加好友、不进群就完成提交？
4. 毕业或换届时，数据能否完整带走或彻底清掉？
5. 不需要它的时候，它是否安静地退到背景？

效率让人有余力，余力才谈得上服务。若只优化点击次数，最终只是把「管人」做得更顺滑。

## 1. 一屏解剖

```
┌──────────────────────── 顶栏 56 ────────────────────────┐
│ 品牌    ⌘K 搜索 / 命令      ✦ AI 副驾    提醒 3   身份 ▾   ⚙ │
├ 侧栏 64/212 ┬──── 主工作区 ─────────────┬ 上下文栏 320 ┤
│ 材料流程     │ 页头：标题 + 角色 + 视图切换 │ 详情 / 核对   │
│  概览        │                            │ 预览 / 留痕   │
│  材料台账    │ 内容：表格 / 矩阵 / 文件室  │ 操作 / 备注   │
│  文件室      │                            │              │
│ 协同跟进     │                            │              │
│  完成矩阵    │                            │              │
│  任务时间线  │                            │              │
│  操作日志    │                            │              │
├──────────────┴────────────────────────────┴──────────────┤
│ 状态栏 26：本地模式 · 材料 7 · 未交 2 · 索引一致          │
└──────────────────────────────────────────────────────────┘
```

五个区的职责，不重叠：
1. **顶栏**：只放身份、搜索/命令、AI 副驾入口、提醒、设置。不放业务按钮。
2. **侧栏**：只放导航与分组，可收束成图标条。不放筛选器和开关。
3. **主工作区**：当前唯一任务。一个视图只允许一个实心主按钮。
4. **上下文栏**：选中对象的全部信息与操作。可收起；窄窗口变浮层。
5. **状态栏**：数据规模、同步/索引状态、快捷键提示。不放操作。

**关键结构判断**：从「整页铺卡片」转向「工作区 + 上下文栏」。这是解决画面僵硬的分水岭——层级由**空间关系**建立，不由描边和阴影建立。

## 2. 三个核心物件，三种最佳视图

| 物件 | 最佳视图 | 形态 |
| --- | --- | --- |
| 材料 Doc | 台账 + 文件室 | 记录视图看状态与流转；文件视图看它到底在哪个文件夹 |
| 人 Student | 完成矩阵 | 行是人、列是材料类别，格子是状态；不是一张平铺名单 |
| 事 Event | 时间线 | 提交/审核/归档/催交按时间排，可筛选、可导出 |

### 2.1 材料台账（记录视图）
- 列：编号、名称、类别、提交人、学号、时间、状态、附件/归位。
- 顶部：搜索 + 类别/类型/状态 + 「保存视图」；列宽、列显隐按视图记住。
- 行：单击选中→右栏出详情；双击不跳页；`Space` 预览。
- 多选：复选框列 + Shift 连选；底部浮出批量条（归档 / 驳回 / 归位 / 导出），显示「已选 5 条」。
- 详情栏三页签：**概览**（属性 + 模板字段）、**文件**（附件、归档路径、在资源管理器打开）、**留痕**（状态变化、经办人、备注）。
- 空态不说「暂无数据」，说「这一屏没有待审材料，最近一条在 11-12」。

### 2.2 文件室（文件视图）
- 左：目录树，镜像归档根目录（类别 / 学号-姓名 / 编号_材料名）。
- 中：文件列表，名称、大小、修改时间、是否在索引内。
- 右：预览（PDF 首页 / 图片 / 文本前 200 字），加「在资源管理器打开」。
- 缺失文件标红点，点一下按索引反查台账；索引与磁盘不一致时，状态栏提示「索引待修 2 项」。
- 拖入文件 → 直接落进当前目录并登记台账；拖出不做移动，避免误伤。

### 2.3 完成矩阵（名单最佳形态）
```
            团务  奖助  学分  宣传  班务   合计
覃祖悦 250201  ●     ●     ●     ●     ●     5/5
赵晓   250205  ○     ○     ○     ○     ○     0/5
孙倩   250210  ●     ○     —     ○     ○     1/5
```
- 格子状态：● 已归档、◐ 待审、○ 未交、— 免交、× 驳回。
- 点格子：有材料→开右栏；没材料→就地「建任务 / 生成催交话术」。
- 列尾合计给「这一类的完成率」，行尾给人「这个人缺几类」。
- 底部一键「复制未交清单」，输出「赵晓：团务、奖助、学分、宣传、班务」。
- 免交要能设：转学、免修、已在校外提交，避免无意义催交。

## 3. 六个场景的最优解

### 3.1 早上打开（30 秒）
首页只回答三个问题：**现在欠什么、谁没交、下一步做什么**。
- 主视觉：待我处理 `3`，最早一条 + 一个主按钮「处理待审」。
- 右侧风险栏：逾期任务、未交人数、驳回待补，按严重度排序。
- 不做全量 KPI 墙；数字只保留会触发动作的那几个。

### 3.2 收材料（一条路径）
- 三种入口统一：表单提交、文件夹扫描、拖入文件。
- 扫描结果不再是一张待确认表，而是「新增 3 / 修改 1 / 删除 0」三行摘要，展开才看明细。
- 入账即可选「同时归位」，避免「先登记、后归位」两次操作。

### 3.3 审材料（不离开列表）
- 选中行→右栏直接看附件预览与模板字段。
- 通过/驳回在右栏底部，驳回必须写一句原因；备注就地输入，不弹窗。
- 批量通过：只对同类别、同状态开放；批量驳回要求统一备注。
- 审核后行状态就地变化，不整表刷新、不丢滚动位置。

### 3.4 归档（文件真的落进文件夹）
- 单条：右栏「归档」→ 按规则算出目标路径→ 预览路径→ 确认。
- 批量：对选中项统一归档，逐条显示成功/跳过/失败，失败可重试。
- 规则：`归档根 / 类别 / 学号-姓名 / 编号_材料名.ext`；类别可映射子目录；重名加序号。
- 索引 `_归档索引.csv` 每次归档后原子重写；文件室可校验索引与磁盘一致。

### 3.5 催交（从矩阵直接生成）
- 选未交的人/类别 → 生成一段可直接粘贴的话术，含缺哪几类、截止时间、提交入口。
- 可复制到微信/群公告；不自动发送，不接第三方账号。
- 催交动作写进日志；同一人 24 小时内不重复提醒。

### 3.6 交差（一键证据包）
- 选时间范围/类别 → 导出 ZIP：`材料清单.csv`、`归档索引.csv`、`操作日志.csv`、`文件树.txt`，可选附文件。
- 包内自带 `README.txt` 说明目录结构与字段，评审方不装软件也能看懂。
- 这是「班级建设成果评比」「资助材料检查」最刚需的出口。

## 4. 交互语法（七条硬规则）

1. **一屏一个实心按钮**：其余是文字链、Ghost 或图标。
2. **能用右栏就不用弹窗**：详情、预览、备注、批量确认全在右栏或底部条。
3. **折叠不是删除**：低频动作进「更多」、分组、设置；原功能一个不少。
4. **命令面板**：`Ctrl+K` 搜材料/人/任务，`>` 前缀执行动作（`>归档`、`>催交`、`>导出`）。
5. **键盘可走完全程**：`↑↓` 选行、`Enter` 开详情、`Space` 预览、`Esc` 收右栏。
6. **状态就地变**：审核、归档、勾选后只更新那一行，不整表重建。
7. **不打断**：非破坏性操作不弹确认；破坏性操作才确认，且写清影响范围。

## 5. 视觉系统（定稿方向）

| 项 | 浅色 | 深色 |
| --- | --- | --- |
| 窗口底 | `#F5F7FA` | `#0E1013` |
| 卡片 | `#FFFFFF` | `#171A1F` |
| 抬升面 | `#F0F2F6` | `#1F242B` |
| 发丝线 | `#E3E7EE` | `#2A2F37` |
| 主字 | `#111827` | `#E7EAF0` |
| 次字 | `#5B6475` | `#9AA3B2` |

- **圆角**：卡片 10、输入 6、标签 4；不做大圆角胶囊堆叠。
- **间距**：4 的倍数；页边 24、卡片间 16、卡片内 14。
- **字阶**：21 页标题 / 13 区块标题 / 11 正文 / 9 辅助；表头 9 加粗降色。
- **配色**：保留十套强调色；状态色只用绿/琥珀/红，底色取 8% 透明度，不做整行染色。
- **图标**：16px 线性、1.5px 描边、同一套；不用 emoji 当图标。
- **层次**：靠表面差与留白，不靠阴影；全应用最多一种极淡投影，且只给浮层。
- **动效**：140–180ms ease-out；只做淡入与位移，不做弹跳、缩放、渐变扫光。

## 6. 双端分工（重要判断）

网页端不该追桌面端的全部功能，应该收敛为**同学侧入口**：
- 网页：免安装提交、查自己的材料状态、看缺什么；轻量、手机可用。
- 桌面：学委/辅导员的管理台，台账、矩阵、归档、催交、证据包都在这里。
- 数据不自动同步；网页明确写「本机浏览器保存」，桌面导出/导入负责搬运。

这比「两端功能对齐」更现实，也更符合真实使用场景：同学不会装 exe，学委不会用手机归档。

## 7. 可靠性（最好模样的底线）

- 本地 SQLite + 原子写；每次归档先写临时文件再改名，避免半截文件。
- 备份：手动 JSON + 每次启动自动滚动备份 5 份；恢复前先预览「将覆盖多少条」。
- 完整性检查：索引↔磁盘↔台账三方比对，给出可修复项；不做静默修复。
- 崩溃日志可一键导出；错误提示说人话，附「下一步怎么办」。
- 性能尺：冷启动 ≤1s、5000 条筛选 ≤100ms、滚动不掉帧、内存 ≤150MB。

## 8. 路线图（从 v0.14 到 v1.0）

### v0.15 上下文版
- 材料详情右栏；多选与批量归档/驳回；完成矩阵；提醒中心。
- 验收：右栏看完就能归档，不离开台账；一次批量处理 5 条；矩阵点格子能开材料或建任务。

### v0.16 规则版
- 模板字段可视化配置；保存视图（筛选+列宽+列显隐）；归档规则模板；命令面板；排序。
- 验收：新增一个模板字段 ≤1 分钟；保存视图一键还原；`>归档` 可执行。

### v0.17 审计版
- 单据时间线；证据包导出；完整性检查；恢复预览；日志筛选。
- 验收：任意材料能看到完整流转链；证据包脱离软件可读；索引不一致能被发现并修复。

### v0.18 服务版
- 免交 / 延期登记；催交话术与同一学生 24 小时限频；同学回执；服务留痕；届别交接包。
- 验收：免交与延期可追溯原因和截止日；同一学生一天内不会被重复催；回执后不再出现在缺失名单；交接包能带走登记与索引。

### v0.19 文件室
- 独立文件室视图：目录树、文件列表与预览、缺失文件反查、拖入登记；与台账、归档索引联动。
- 验收：找任意一条材料对应文件 ≤2 个动作；缺失文件能被反查并定位到责任人。

### v0.25 AI 副驾（与功能补齐同版推进）
- 顶栏 `✦ AI 副驾` 入口；右栏增加「AI 建议」页签，先接材料详情、完成矩阵、催交三个高频点。
- 概览从七卡收到“三个问题 + 一个主按钮 + 一条下一步”；顶栏收掉业务按钮。
- 完整 AI 助手保留，入口从「更多」提到「智能辅助」，不删已有双通道能力。
- 验收：选中一条材料，右栏一次点击出“缺项 + 驳回草稿”；不跳页、不改台账、日志可查；关掉 AI 后主流程零阻断。

### v0.26 功能补齐（混合流程）
- 收材料扫描三行摘要、矩阵格直接建任务/生成催交、全局搜索覆盖人/任务/文件、详情右栏升级为上下文栏。
- 桌面接 API-only AI 建议，默认关，从分类建议切入；未配置回退本地规则。
- 验收：矩阵格到催交话术 ≤2 次点击；找任意材料/人/文件 ≤2 个动作。

### v1.0 静默版
- 首次引导（3 分钟走到第一条归档）；空态/错误态全套；性能达标；安装包与说明定稿。
- 验收：新用户不看书就能完成一次提交→审核→归档；全流程无弹窗链；两套主题逐视图一致。

## 9. 不做清单

云盘与跨设备同步、账号体系与多人实时协作、插件/技能市场、AI 素材生成与模型档位、以聊天窗口为主入口的独立 AI 应用、移动原生 App、多班级多租户。

## 10. 验收尺（判断「到没到最好」）

1. 单条材料从选中到归档 ≤3 次点击、≤20 秒。
2. 找任意一条材料/一个人/一个文件 ≤2 个动作。
3. 每日巡检（待审 + 未交 + 逾期）≤2 分钟。
4. 归档索引与磁盘文件一致率 100%，无孤儿文件。
5. 任意一屏只有一个视觉重点，去掉任意一张卡片都不会破版。
6. AI 建议从选中对象到出草稿 ≤1 次点击；不跳页、不改数据、生成记录可查。
7. 不装 AI 也能走完全流程；关掉 AI 后主流程零阻断。

## 11. AI 副驾落位（不是第四个物件）

AI 不新增一个核心物件，而是挂在材料、人、事三个物件之上的**副驾层**：

| 落点 | 位置 | 触发 | 输出 |
| --- | --- | --- | --- |
| 顶栏入口 | `品牌 / ⌘K / ✦ AI 副驾 / 提醒 / 身份 / ⚙` | 任何时候点开 | 右栏 AI 面板，不跳页 |
| 对象建议 | 右栏「AI 建议」页签 | 选中材料 / 人 / 任务 | 缺项、驳回草稿、催交话术、情况说明、复盘提纲 |
| 流程建议 | 收材料扫描、批量审核、催交、证据包 | 走到该节点 | 摘要、核对清单、可复制文案、目录说明草稿 |
| 高级对话 | 更多 → 智能辅助 → AI 助手 | 复杂任务、模型配置 | 现有双通道完整对话，作为兜底 |

三条硬边界：
1. **只读上下文，不自动写**：AI 不改台账、不改状态、不发消息、不归档；执行动作要人再点一次。
2. **默认本地，API 明示**：网页默认本地模型；切 API 时明确提示上下文会离开设备；桌面 AI 默认关、未配置回退规则。
3. **生成留痕但不污染业务日志**：AI 记录单独标 `src=AI`，与提交/审核/归档日志分开筛选。

桌面端不搬 WebGPU：先接 OpenAI 兼容 API，从收材料/拖入文件的分类建议切入，结果人工确认后才入账。
