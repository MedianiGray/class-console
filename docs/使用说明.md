# 工作台使用说明

> 面向班级学委、辅导员老师的操作手册。照着本说明即可完成材料收集、审核核对、留痕与备份。
> 本工具是**离线本机工具**：数据保存在自己这台电脑上，断网可用；不需要注册账号，也不把材料传到网上。

## 一、这是什么

班级材料操作台，把一份材料从"交上来 → 审核 → 归档 / 驳回 → 留痕"的过程收拢在一个窗口里完成。提供两种形态，功能一致、数据各自独立：

- **桌面版（Windows exe）**：双击独立运行，数据存在本机 SQLite 数据库。
- **网页版（单文件 HTML）**：用浏览器打开，数据存在浏览器本地缓存（localStorage），可挂在 GitHub Pages 上做预览。

> 两端数据互不同步：桌面版里录入的材料不会出现在网页版，反之亦然。需要迁移时用各自的备份功能导出导入。

## 二、界面布局

左侧为导航栏，右侧为当前视图；左下角可切换岗位视角（经办人 / 审核者 / 汇总者 / 申请人），当前身份在底部状态栏留痕；底部状态栏同时显示本地模式与条数，操作后会有临时提示。

| 操作 | 经办人 | 审核者 | 汇总者 | 申请人 |
|---|---|---|---|---|
| 查看台账、详情 | 可 | 可 | 可 | 可 |
| 提交、编辑材料 | 可 | 可 | — | 可 |
| 归档 | — | 可 | 可 | — |
| 驳回 | 可 | 可 | 可 | — |
| 导出 CSV | 可 | 可 | 可 | — |
| 批量导入材料（CSV 入账） | 可 | 可 | — | — |
| 名单添加 / 移除 / 清空 | 可 | 可 | 可 | — |
| 任务添加 / 编辑 / 删除 | 可 | 可 | 可 | — |
| 勾选任务完成 / 还原 | 可 | 可 | 可 | 可 |
| 导入备份 | — | 可 | 可 | — |
| 查看操作日志 | 可 | 可 | 可 | — |

> 视角切换为本地演示性质，未接账号密码登录；真正按身份强制限权需要后端，见《能力范围评判.md》。

| 导航项 | 用途 |
|---|---|
| 工作台概览 | 一眼看清材料总数、待审核、已归档、已驳回，以及未交人数、临期 / 逾期任务 |
| 材料台账 | 全部材料的列表，可搜索、筛选、查看详情、归档或驳回 |
| 名单核对 | 班级学号—姓名名单，对照材料记录谁交了、谁没交 |
| 任务跟踪 | 待办事项与截止日期，自动提醒临期、逾期 |
| 提交材料 | 录入一份新材料 |
| 操作日志 | 所有提交、查看、归档、驳回的留痕记录 |

## 三、各视图操作

### 3.1 工作台概览

- 材料四态卡片（总数、待审核、已归档、已驳回）全员可见；未交材料卡需名单维护权，临期 / 逾期任务卡需任务管理权，无对应权限的岗位不显示。
- 中部显示各类别材料数量分布；右栏按权限让位：有日志查看权显示近期动态，无日志权但有名单权时显示未交材料清单（点击直达名单视图），两者皆无则右栏留空。
- 待办队列按岗位拆分：申请人看「需我关注的材料」（待审核 + 已驳回），审核者 / 汇总者看「待审核 · 需处理」，经办人看「待审核 · 跟进」；点击条目可跳到台账。
- 台账默认筛选：审核者 / 汇总者默认「待审核」，其余岗位默认「全部」；在台账内手动改的筛选不会因切换岗位被覆盖。

### 3.2 材料台账

- **搜索**：在顶部输入材料名、姓名或学号，实时过滤。
- **筛选**：按类别（团务 / 奖助 / 学分 / 宣传 / 班级事务）、按状态（待审核 / 已归档 / 已驳回）筛选。
- **查看**：选中一条，双击或按回车，或点"查看"，弹出详情；详情内附该材料最近的操作记录。
- **归档 / 驳回**：按岗位权限点显示（归档：审核者 / 汇总者；驳回：经办人 / 审核者 / 汇总者）。选中材料后点"归档"或"驳回"，在弹出的备注框里可填写说明（可选，驳回建议写明原因），确定后状态更新并自动写入日志。
- **导出 CSV**：把当前筛选出来的记录导出为 CSV 文件，可用 Excel 打开。

### 3.3 名单核对

- 顶部统计应交、已交、未交人数。
- **添加成员**：填写学号（纯数字）与姓名保存；学号重复或格式不对会被提示。
- **移除选中**：从名单中删掉一名成员。
- 核对口径：名单内学号在材料记录中出现过即视为"已交"；材料里有学号但名单中没有，记为游离材料，便于发现录错学号。

### 3.4 任务跟踪

- 顶部统计进行中、临期（截止日 ≤2 天）、逾期、已完成数量。
- **添加任务**：填写标题、关联类别、截止日期（格式 YYYY-MM-DD）、应交范围、备注。
- **编辑**：选中任务后修改内容。
- **完成 / 还原**：切换任务是否已完成。
- **删除**：删除选中任务（需确认）。

### 3.5 提交材料

1. 填写材料名称、姓名、学号、材料类别；说明和附件为可选。
2. 学号须为纯数字；必填项留空或学号格式不对时，表单下方会就地提示，材料不会入库。
3. 如与已有记录学号、材料名、类别重复，会提示确认是否再次提交。
4. 点"提交材料"，新材料进入台账，状态为"待审核"，日志新增一条"提交"。
5. "清空"会撤销当前已填内容，已填写时需确认。

### 3.6 操作日志

- 记录每条操作的时间、操作人、角色、动作、对象和来源。
- **导出备份**：把材料、日志、名单、任务打包为 JSON 文件保存。
- **导入备份**：选择此前导出的 JSON 文件；导入会覆盖本机当前全部数据，需二次确认，结构不正确或失败时回滚不写入。

## 四、一次材料收集的完整流程

1. **提前建名单**：到"名单核对"把本班学号—姓名录入。
2. **登记任务**：到"任务跟踪"建一条收集任务，写清截止日期和应交范围。
3. **申请人 / 经办人提交**：在"提交材料"录入，或由经办人把收齐的材料逐条登记进台账。
4. **审核**：审核者 / 汇总者在台账查看详情，合格的归档，不合格的驳回并注明原因。
5. **核对**：回到"名单核对"对照未交人员，据此催办。
6. **收尾**：在任务跟踪把已完成的任务标记完成；导出一份 JSON 备份留存。

## 五、备份与恢复

- **备份**：操作日志视图 → "导出备份"，选择保存位置，得到一个 `.json` 文件。请在学期中段和收尾时各导出一份，妥善保存。
- **恢复**：换电脑或误操作后，在操作日志视图 → "导入备份"选择该 JSON 文件，确认后材料、日志、名单、任务一并恢复。
- 备份文件是纯文本 JSON，可用文本编辑器查看内容；其中包含学号、姓名等信息，请按敏感材料保管。

## 六、数据存放位置与隐私

- **桌面版**：数据目录在 Windows 的 `%APPDATA%\ClassConsole\`
  - `console.db`：材料、日志、名单、任务数据库。
  - `crash.log`：未捕获异常的错误日志。
  - `console.corrupt-*.db`：数据库损坏时隔离保留的旧文件。
- **网页版**：数据保存在当前浏览器的本地缓存；清理浏览器站点数据会清除网页版记录，清理前先导出备份。
- 程序默认不主动联网；不收集、不上传个人信息。学号、姓名等仅用于本机台账与核对。

## 七、常见问题

**换电脑后历史附件打不开？**
当前版本附件只记录文件名，文件本身没有落盘保存。需要在换电脑前把原始文件一并带走。附件真实落盘属于待做能力（见《能力范围评判.md》B 类）。

**材料丢了 / 误删怎么办？**
如果此前导出过 JSON 备份，用"导入备份"恢复；没有备份的本地记录无法找回。建议定期备份。

**网页版和桌面版记录对不上？**
两端存储相互独立，不互通。确认自己在哪一端录入，到对应端查看。

**为什么看不到归档 / 驳回、导入、名单维护、任务增删或备份导入按钮？**
当前岗位视角没有对应权限点，这些入口按岗位裁剪显示；在左下角切换到具备该权限的岗位即可。该视角切换是演示性质，未接账号密码登录，也不是服务端强制权限。

**导入备份提示结构不正确？**
所选文件不是本工具导出的备份，或文件已损坏。请重新选择此前导出的 `.json` 备份。

## 八、能力边界（务必知悉）

- 本工具是单机离线台账，**没有**账号登录、多人协作、跨设备同步、云端附件和在线提交功能。
- 岗位切换只做界面层裁剪，不做服务端真实权限校验，也无记录级数据范围隔离，不能作为防越权依据。
- 尚未在不同 Windows 版本、分辨率、字体缩放和大批量数据下做过长时实测。
- 哪些能做、哪些需要后端、哪些属于规划关闭项，完整对照见《能力范围评判.md》。
