## 二、扩展排期

### P0（v0.14 已交付）
- 应用外壳、三层表面、十套强调色 + 取色盘、三档密度、侧栏分组折叠、全局搜索、身份卡切换。
- 概览主视觉带 + 待办 / 类别 / 动态三卡；台账卡片容器与轻量「更多」；提交表单限宽卡片；名单双栏核对。

### P1（v0.14.2 桌面 / v0.15.0 网页已交付）
1. **材料详情侧栏**：右侧常驻详情，含属性、附件、归档路径、审核备注与审批节点；列表上下文不丢。
2. **多选与批量归档**：Ctrl / Shift 多选，批量归档、批量驳回（统一备注），选择在刷新后保持。
3. **提醒中心**：顶栏常驻入口 + 待办角标，聚合待审、驳回、临期任务、未交名单，可一键跳转。
4. **模板可视化配置**：设置里增删附加字段（名称 / 必填 / 类型 / 下拉选项），提交表单、详情与导出自动跟随。

### P2（中期）
- 归档规则配置（类别 → 子目录、命名模板变量）已落地；打开归档目录后的本地检索、自动归档待补。
- 两端列宽拖拽 / 记忆 / 重置、命令面板、命名保存视图、名单完成矩阵已落地（v0.16.x）。
- 两端 token 同源：网页端已跟上桌面端的三层表面与配色（v0.15.0），后续只做细节同步。

### 边界外（明确不做）
- 云盘 / 跨设备同步、账号体系与在线协作。
- 插件 / 技能市场、AI 素材生成、模型档位。
- 独立聊天窗口与多会话。

## 三、视觉与交互原则（本轮定稿）

1. **三层表面**：窗口底负责分区，卡片承载内容，抬升面只给输入框、轨道与次级容器；不靠阴影堆层次。
2. **一屏一个主动作**：概览只允许 hero 里一个实心主按钮，其余是文字链或 Ghost。
3. **信息三级字号**：21 号页标题、10 号正文、9 号辅助；表头 9 号加粗、颜色降一级，不与内容抢。
4. **折叠而不是删除**：所有既有功能保留，低频动作收进「更多」、侧栏分组、设置弹窗；需要时再点。
5. **参数进设置**：外观、密度、侧栏、默认视图、归档策略、模板字段、备份恢复集中在独立弹窗，主界面不摆开关。
6. **留白按区块给**：页头 24、卡片间 16、卡片内 14；表格行高随密度，不靠加粗分隔线。
7. **可以弱但不能没有**：每类办公能力至少保留最小入口或模板；实现可以简化，不能整块缺席，也不放假按钮。暂不具备的以「只读 / 本机 / 外部入口」明确说明。
