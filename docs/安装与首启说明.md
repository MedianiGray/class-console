# 桌面版安装与首启说明

> 适用：Windows 10 / 11（64 位），`v0.27.2` 及之后版本。0.28.0 起文件室多出「批量工具」（重命名 / 转换 / 归位），安装步骤不变；安装包发布前仍下载 v0.27.2。
> 目标：不装 Python，下载后能打开；第一次打开知道先做什么；数据在哪、怎么迁、怎么卸载，一句话能查到。

## 一、下载与校验

v0.27.2 提供两种包，按用途选：

| 包 | 适合 | 启动方式 | 同机已有数据启动 |
| --- | --- | --- | --- |
| `class-console-v0.27.2-portable.zip`（推荐） | 固定在一台电脑上用 | 解压一次，之后双击 `班级操作台.exe` | 窗口约 1 秒出现（中位 0.98 秒）；当前页约 1.5 秒补齐 |
| `class-console-v0.27.2.exe` | U 盘带走、临时换机 | 单文件双击，每次先解包 | 约 3–8 秒，受安全软件影响更大 |

1. 打开 [Releases](https://github.com/MedianiGray/class-console/releases)，进入 `v0.27.2`。
2. 下载 `class-console-v0.27.2-portable.zip`，解压到一个固定目录（例如 `D:\Tools\班级操作台`）。不要直接在压缩包里双击运行。
3. 需要单文件时再下载 `class-console-v0.27.2.exe`。
4. 校验文件是否完整（可选，建议首次分发时做）：

```powershell
Get-FileHash ".\class-console-v0.27.2-portable.zip" -Algorithm SHA256
Get-FileHash ".\class-console-v0.27.2.exe" -Algorithm SHA256
```

v0.27.2 的期望值：

| 项 | 值 |
| --- | --- |
| 便携包大小 | 32,994,326 字节 |
| 便携包 SHA256 | `8E7F232037AE23FACA6CF6131DBADA0E6B0920B75DB509A1C4807902827843CE` |
| 单文件大小 | 32,362,641 字节 |
| 单文件 SHA256 | `550B03A0FD5B524492ACD38507E923A84AF7C8B7EFC82A5819ECD9CE1DAE9691` |

哈希不一致就不要运行，重新下载。仓库不提交 exe/zip，所有安装包只走 Release 附件。

## 二、第一次打开

便携版解压后双击 `班级操作台.exe`；单文件版直接双击 exe。都不需要安装、不需要管理员权限、不会写注册表。

1. **SmartScreen**：程序没有商业代码签名，Windows 可能提示“已保护你的电脑”。点“更多信息 → 仍要运行”。这是未签名程序的正常提示，不是病毒结论；不要为此关闭系统防护。
2. **启动时间**：双击后先出品牌加载页，再出主窗口外壳，最后补当前页内容。便携版同机已有数据：窗口约 1.0 秒可见（实测中位 0.98 秒，个别次数 1.03–1.08 秒），概览内容约 1.5 秒补齐；干净目录第一次要建库，约 2.5 秒出窗口、约 3.0 秒补齐内容。单文件版每次启动还要解包，通常 3–8 秒，受安全软件影响更大。机器较慢或安全软件正在扫描时会再慢一些，属正常启动；加载页出现前不要重复双击。
3. **首次建库**：第一次打开会创建空库并写入少量示例数据，约 2–3 秒。示例材料、日志、名单、任务均可一键清空，不计入首次引导进度。
4. **三步上手**：概览顶部出现可收起的“三步上手”卡：录入或收集第一份材料 → 审核并归档 → 核对名单或登记任务。完成前两步会自动收起；从“设置 → 使用帮助”可以重新显示。
5. **岗位**：左下角可切换经办人（学委）、审核者（辅导员）、汇总者（负责人）、申请人（同学）。不同岗位看到的入口不同；这是本机界面层的视角切换，不是账号登录。

建议第一次走一遍：

1. “提交材料”填一条真实或脱敏材料，提交。
2. 切到经办人或审核者，在“材料台账”里审核并归档。
3. 回概览，确认前两步打勾，状态栏材料数与台账一致。
4. “设置 → 数据 → 导出备份”，保存一份 JSON，确认能打开。

全程不需要联网。只有启用桌面 AI 分类建议时才会访问你配置的 API 地址。

## 三、数据存在哪

默认位置：

```
%APPDATA%\ClassConsole\
├── console.db                # 主数据库（材料、日志、名单、任务、服务记录）
├── settings.json             # 界面、归档、AI 配置
├── crash.log                 # 仅在启动或界面异常时出现
└── console.corrupt-*.db      # 仅在数据库损坏时隔离出的旧文件
```

在资源管理器地址栏粘贴 `%APPDATA%\ClassConsole` 可直接打开。

- 数据只在本机，不上传云端；程序不要求账号，也没有多人同步。
- 程序不会自动滚动备份，退出前或重要操作前需手动“设置 → 数据 → 备份到文件”。
- 网页版数据在浏览器 `localStorage`，与桌面库**互不同步**。同一份材料不要在两边的库里各记一次还以为已同步。
- 备份 JSON 含材料、日志、名单、任务、模板字段、附件记录、流转事件与服务记录；归档原件是否在备份里，取决于是否使用“交接包”并勾选附带文件。
- `settings.json` 的 `ai` 段保存 API 地址、模型、超时和 Key。Key 为本地明文存储，只应使用自己的 Key，不要把 `settings.json` 发给别人。

## 四、换机与迁移

推荐用内置备份，不要直接复制正在运行的数据库文件。

1. 旧机：设置 → 数据 → 导出备份，得到 JSON；需要原始归档文件时同时导出交接包 ZIP。
2. 新机：安装同版本或更新版本，先打开一次让程序建库。
3. 新机：设置 → 数据 → 导入备份，先看数量、重复编号与覆盖预览，确认后导入。
4. 归档原件按原目录结构复制到新机的归档根目录，再在“文件室”核对缺失文件。

不要在程序运行时复制或覆盖 `class_console.db`：Windows 会锁文件，复制出来的库也可能处于写事务中间状态。程序检测到损坏库时会把原库改名隔离并重建，开机说明里会给出原库位置；先保留该文件，再做恢复。

## 五、更新与卸载

**更新**

1. 关闭正在运行的旧程序。
2. 便携版：把新 zip 解压覆盖到同一目录（保留 `%APPDATA%\ClassConsole` 不动）；单文件版：用新 exe 替换旧 exe。
3. 双击新程序，数据目录不变，材料与设置自动沿用。
4. 若新版提示数据库需要迁移，先按提示导出备份再继续。

**卸载**

1. 关闭程序。
2. 便携版删除整个程序目录；单文件版删除 exe。
3. 如不再需要数据，再删除 `%APPDATA%\ClassConsole`。删除前先导出备份；该目录删除后无法从程序内恢复。
4. 程序不写注册表、不装服务、不开机自启，删除上述两项即清理完成。

## 六、常见问题

| 现象 | 可能原因 | 下一步 |
| --- | --- | --- |
| 双击后很久没窗口 | 单文件版解包 + 安全软件扫描；便携版被安全软件拦 | 便携版正常 1–4 秒内应出现加载页；超过 10 秒看任务管理器是否有进程，结束后重开 |
| 新解压目录首次特别慢 | 安全软件全盘扫描、磁盘索引未缓存（常见于机械盘或外接盘） | 放到本机固定目录，首次允许扫描完成；之后同目录启动会回到 1–2 秒量级 |
| 解压后提示缺少 DLL/文件 | 只复制了 exe，没带 `_internal` 目录 | 整个文件夹一起解压，保持 `班级操作台.exe` 与 `_internal` 同级 |
| SmartScreen 拦住 | 未签名程序 | “更多信息 → 仍要运行”；不要关闭系统防护 |
| 提示“数据库损坏，已隔离重建” | 断电、磁盘错误、运行中复制 | 在 `%APPDATA%\ClassConsole` 找隔离出的旧库；用最近备份恢复 |
| 归档失败、原件还在 | 归档目录无权限、磁盘满、同名冲突 | 换有写权限的目录；清理空间；同名不会覆盖，按提示改名或保留 `_v2` |
| 文件室看不到缩略图 | Windows Shell 无该类型预览 | 右键“系统打开”；不影响登记与查找 |
| AI 建议回退本地规则 | 未启用、无 Key、401/403、429、5xx、超时、断网 | 设置页检查地址、模型、Key 与额度；不启用也能用本地关键词规则 |
| 窗口被裁、字太小 | 系统缩放 125% / 150% | 程序已声明 DPI 感知；仍异常时把缩放调回 100% 复现并记录 |
| 启动报错后闪退 | 未捕获异常 | 打开 `%APPDATA%\ClassConsole\crash.log`；设置 → 关于也可导出 |

## 七、边界

- 仅 Windows 桌面；不支持 Windows 7、32 位系统、macOS、Linux。
- 不提供账号、云同步、多人实时协作、自动更新服务端。
- 不承诺绕过 SmartScreen 或企业终端管控；被组织策略拦截时联系本单位管理员。
- 性能与数据能力边界见 [`业务验收对照与走查表.md`](业务验收对照与走查表.md)；桌面 5000 条场景的实测与例外见该文档第五节。
