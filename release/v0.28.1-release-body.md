# v0.28.1 启动提速版 · 窗口 0.83 秒出现，包体瘦 30MB

上一版（0.28.0）为了加文件批量工具，启动退回了约 0.4 秒。这一版把它收回来：**界面分三层长出来**，先让你看见窗口，再把内容补齐；顺手把安装包里从没用过的 numpy 拿掉，包体从 33MB 降到 21MB。

## 启动分三层

1. **第一帧**：只有顶栏品牌块（「文」方块 + 班级操作台）、侧栏底色和状态栏，内容区一行“正在打开工作台…”。窗口在这个状态下就已经能看、能拖动。
2. **第二帧**：页头、视图容器、侧栏 9 行导航、身份卡，紧接着建当前视图并刷新——“当前页可读”不再等顶栏右侧的搜索框和按钮。
3. **第三帧**：顶栏搜索框、Ctrl K、设置、提醒、身份卡，以及新手引导卡。晚 0.2–0.3 秒出现，不影响主内容。

配套改动：顶栏拆成“核心 + 附加”两批构建（顶栏从 275ms 降到 51ms）；侧栏 9 行导航由 `Button` 换 `Label` + 点击绑定（外观与点击行为不变，少付一批控件初始化）；加载页从 6 个控件的品牌卡缩成一行字。原来的“去掉加载窗更快”试过了，实测反而慢 20–40ms（加载窗先把窗口和字体栈热身了一遍），已回退，加载页保留。

## 包体瘦身

打包时发现 `numpy.libs` 20.2MB + `numpy` 6.1MB 一直躺在包里，而全仓库**从未 import 过 numpy**——它是 Pillow 打包钩子顺手带进来的（图片相关代码都是函数内延迟 import PIL，不需要 numpy）。打包脚本改为排除 `numpy / numpy.libs / scipy / pandas / matplotlib`：

| 产物 | 0.28.0 | 0.28.1 |
| --- | --- | --- |
| 便携目录 | 77 文件 / 71,639,812 字节 | 36 文件 / 41,300,944 字节 |
| 便携 zip | 33,022,547 字节 | **21,217,941 字节** |
| 单文件 exe | 32,392,545 字节 | **20,842,874 字节** |

Pillow 完整保留（11.2MB 原样在包里）。为确认功能没塌，用“把 numpy 屏蔽掉”的解释器跑了一遍图片转换：PNG → WEBP 成功，`{'ok': 1, 'failed': []}`。

| 口径 | 窗口可见 | 内容就绪 |

| 便携版 0.28.0 | 中位 1404.2ms | 中位 2117.6ms |
| 便携版 0.27.2（基线） | 中位 977.8ms | 中位 1514.9ms |

**口径说明，请照实看**：中位 0.83 秒 / 1.42 秒，双双进入 1 秒与 1.5 秒区间，比 0.27.2 基线还快 149ms / 98ms。但 6 次里各有 1 次没进区间（窗口 1036.8ms、内容 1668.8ms）——所以这次记 **“中位达标、个别次数未达标”**，不称“1 秒开机”，也不写“全部达标”。门禁页按同样口径记录。

单文件版（3 次）：窗口 3475.9 / 2068.0 / 2378.6ms，中位 2378.6ms；内容 4530.7 / 2699.0 / 3140.0ms，中位 3140.0ms。每次双击都要解包，这部分成本没变；新文件第一次仍可能被杀软全量扫描，超过 30 秒属正常。
