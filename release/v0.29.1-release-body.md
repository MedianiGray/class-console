## 班级操作台 v0.29.1 · 接话版

**一句话**：0.29.0 的助手只是问答框；这一版让它记得住人、看得见你在看哪份材料、展开就先开口。

### 三件补上的事
1. **记人**：说过一个人之后，直接说「他缺什么」「给他写催交话术」，落到同一个人。
   - 实测：问「250201 还缺什么」→ 答覃祖悦；接「他缺什么」→ 首行仍是「覃祖悦 250201」；再「给他写催交话术」→ 话术里就是覃祖悦。
   - 没有上文时说「他缺什么」，它回「你指的是哪位？给个姓名或学号」，**不编人名**。
2. **看当前材料**：在「材料台账」选中一行，问「这份什么情况」。
   - 实测：选中「事务-002 体测成绩统计表 · 刘一帆 250222 · 班级事务 · 待审核」，答「这份：刘一帆 250222 · 班级事务 · 待审核 / 提交 11-14 11:07 · 文件「体测成绩统计表」/ 同人其余：还缺 团务、奖助、学分、宣传」。
   - 问「这份能归档吗」，它只报事实并加一句：能不能归档要看类别与材料齐全度，这个判断我不替你做。
3. **主动开口**：第一次展开先给「今天：待审 3 份、2 人未交」，纯本地查库、不联网；收起态副行显示最近一句。

### 写操作：说得更明白，仍然不做
- 「把这份材料直接归档」「帮我把台账清空」「替我驳回这份」→ 现在回的是**拒绝理由 + 正确入口**（材料台账里选中后点按钮），不是含糊的「没听懂」。
- 返回 `ok=False / action=unknown`，台账、状态、文件都没动。

### 修了一个真问题
上下文原先在后台线程读 Tk 的选中行——Tk 只认主线程，异常被吞掉，于是「这份」永远是空的。GUI 冒烟当场复现。现在改成：发送前在主线程拍快照，后台线程只读快照。

### 顺手改的
- 展开面板 322×468 → **322×508**，能多放一行长回答；
- 快捷问四个 → 五个：概览 / 谁没交 / 待审 / **这份** / 帮助；
- 帮助里直说 AI 通道状态：没配就写「未接，我按本地规则理解，不联网」，不装懂。

### 测试
- `tests/selftest.py` **52 组**全绿（新增第 52 组：主动开场、跨轮指代、无上文不猜人、当前材料、写操作回绝）。
- `tests/gui_smoke.py` **27 段**全绿（悬浮助手段加三步：展开即有「今天：」、选台账一行问「这份」、问一人后接「他缺什么」落到同一人）。
- 真实库探针（8 人 / 7 份材料）复跑：概览、缺项、催交、待审、指代、这份、回绝全部符合预期。

### 安装

- 备选 `class-console-v0.29.1.exe`（20.9MB / 20,882,778 字节），单文件免解压。
- 便携包 SHA256 `42510BA401B98CFA52FD5F2A50E73A4EFF3C69BA7A4B56D9EB835093841EFF1E`；单文件 SHA256 `56FCF2964FE9F7CC244311E8AB9E170C61878E81A65D3F1015D7B0D4AE95A4C0`。

### 实测说明
本版未改启动路径（只改助手逻辑与面板高度）。打包后跑了 3 次外部就绪：14.1 / 5.5 / 3.4 秒 — 首启 14.1 秒是杀软对新包全量扫描，且当时机器刚跑完两轮打包。样本只有 3 次且环境不同，**不作版本对比**；性能口径仍以 0.28.2 那批 12 次中位 721.0 / 1218.0ms 为准。

### 还是没做
- 写操作（代登记、代归档、批量改状态）依然不做；助手只读。
- 没有待机动画、表情、托盘图标——现在的“常驻”是卡片 + 右键「开机自动显示」，不做假动效换帧率。
