## 班级操作台 v0.29.2 · 顺手版

**一句话**：0.29.1 的助手会接话了，但入口还笨——只能点顶栏或看见那张卡片才能叫它。这一版照大厂的做法把入口补齐：叫得出来、跟得上、上下文摆在明面上、能改名。

### 它是照着谁做的
- **飞书 AI 助手**：固定在页面右下角的悬浮入口；位置类型可选 固定 / 相对 / 粘性；上下文以一个对象传给 AI。
- **飞书智能伙伴**：可以设置名字和头像，常驻在工作流里，有记忆、会主动工作。
- **钉钉 AI 助理**：悬浮球随时唤起，长按可语音遥控、识别当前屏幕问答；7.6.40 把「执行前必须先点一下行动按钮」也去掉了。
- **Microsoft 365 Copilot**：Word / Excel / PowerPoint 里统一的角落按钮，跨应用统一 `Alt + C`，按下去焦点直接进聊天输入框。

这四家的共同点不是「加功能」，而是**入口永远够得着、上下文不用人解释、称呼可以是你自己的**。0.29.2 就补这三件。

### 补了什么
1. **全局热键 Ctrl+Alt+A**
   - `ctypes.windll.user32.RegisterHotKey` 注册，注册与消息循环放在同一后台线程（Windows 的热键消息只投给注册它的线程），命中后经队列回 Tk 主线程，展开并把焦点送进输入框，收起来再按一次。
   - **被别的软件占用时如实降级**：注册返回 0 就不假装能用——右键菜单显示「全局热键：不可用（点我即可）」，帮助里的「唤起：」写清被占用，而不是继续宣传快捷键。
2. **跟随主窗口**
   - 默认贴主窗口右下角内侧 18px，窗口移动、缩放、最大化它都跟着；主窗口最小化到看不见时退回屏幕右下角。
   - 拖它一下就等于说「别跟着我」：自动关闭跟随并记住位置；右键「跟随主窗口：开 / 关」可以再打开。
   - 展开时以右下角为锚点向左上长，不会先跳一下再展开；窗口右侧放得下面板时直接停到窗口外，不压台账右栏的「材料详情」和「朗读」。
3. **上下文摆在明面上**
   - 展开时面板顶部一行：`当前：材料台账 · 选中 事务-002 刘一帆 250222`。
   - 每答完即时重拍快照刷新；切页、改选中都跟着变。没有选中时写「没选中具体材料」。
   - 这一行是给人看的：看见它，你才敢直接说「这份」「他缺什么」。
4. **可以为它改名**
   - 右键「给助手改名…」，8 字以内，存本机；标题、头像首字、下次开机一起换，留空恢复「班级助手」。
5. **收起态更轻**
   - 306×80 → **288×68**，仍保留最近一句（截 16 字），少挡一点底层表格。

### 明确不做的
- **识别当前屏幕**（钉钉那套）：要额外采集屏幕内容，这个工作台的材料本来就敏感，不做。
- **语音唤醒**：要常驻麦克风与本地模型，收益和风险不匹配。
- **写操作**：仍然不代登记、不代归档、不改状态。台账是唯一事实源，改错了没人兜底。

### 测试
- `tests/selftest.py` **53 组**全绿（新增第 53 组「入口交代」：帮助必须有「唤起：」；被占用时写「占用」；没有热键注记时退回「点我，或用顶栏」）。
- `tests/gui_smoke.py` **27 段**全绿（新增：默认跟随主窗口、展开画布出现「当前：」、切到台账选中后上下文行含「材料台账」）。

### 安装

- 备选 `class-console-v0.29.2.exe`（20.9MB / 20,885,450 字节），单文件免解压。
- 便携包 SHA256 `B9F22928FD1746135BA8A9BB9813F4A6E310FB33F7D34CC08144D700C8F1F660`；单文件 SHA256 `51142EE5E73BD7FC2C126AC1BC170F60740C6F4CDE8C2192C937065041592E4D`。

### 实测说明
启动路径未动（只加了热键线程与窗口跟随）。重建包在本机连续 3 次外部内容就绪 **1.62 / 1.31 / 1.20 秒**；同一包首轮因新文件被杀软全量扫描，2 次超过 30 秒、1 次 5.8 秒，之后 4.4 / 3.1 / 4.7 秒——差别在扫描，不在代码。样本少，**不作版本对比**；性能口径仍以 0.28.2 那批 12 次中位 721.0 / 1218.0ms 为准。
