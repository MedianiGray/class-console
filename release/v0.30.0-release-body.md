## 班级操作台 v0.30.0 · 能力中心版

侧栏末位的「更多 → 更多功能」原本是照系统级溢出菜单做的收纳抽屉：既不是栏目，也不是模块，每多一个能力就往下续一层，长期会长成第二套导航。这一版把它拆出来，单独做成**能力中心**：只负责找到并打开，不承担业务动作。

### 变了什么

- **侧栏少一层**：两端去掉「更多」分组和「更多功能」弹窗，在「办理材料 / 跟进核对」之后加一级「能力中心」。原来要点两层才到的地方，现在一层就能看到。
- **一页分组卡**：智能辅助（AI 助手 / AI 建议）、文件与留痕（文件夹收集、操作日志）；网页另加「备份与恢复」，桌面另加「证据包」。卡片只做打开，提交、审核、归档仍回原页面。
- **页内能搜**：输入「备份」「日志」就只剩对得上的卡；没有结果时提示换个词，不留空白页。
- **权限先摆明**：当前岗位用不了的卡置灰并写明原因；申请人看不到备份导出，备份卡要有日志权限才给操作，避免从能力中心绕过日志页拿全量数据。
- **旧入口清理**：网页与桌面的旧「更多」代码、样式、`ui_more.py` 全部下线，不留第二套导航。

### 两端版本

- 桌面端 **v0.30.0**，网页版 **v0.28.0**（Service Worker 缓存键 `cc-web-v0280-shell-v1`）。
- 从 0.29.x 升级只需替换程序目录；`%APPDATA%\ClassConsole` 里的材料、名单、任务与日志不动。
