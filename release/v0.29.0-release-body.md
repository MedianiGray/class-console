## 班级操作台 v0.29.0 · 助手版

**一句话**：桌面右下角多了一张小卡片。你跟它说一句人话，它在本机把台账查出来、把话术写好、把页面切过去——不是又一个按钮。

### 这个助手是什么
- 收起时是一张 306×80 的圆角卡（头像 + 最近一句回答），不抢焦点、不占主窗口空间；
- 点一下展开成对话框，回车即问；可拖动、会记住位置；
- 右键管「打开主窗口 / 朗读最近一条 / 开机自动显示 / 收起 / 关闭」；
- 顶栏右侧新增「✦ 助手」入口，点一下就叫出来。

### 它会做的八件事
| 你说 | 它做 |
| --- | --- |
| 现在台账什么情况 | 报总量、待审、已归档、未交人数、近 7 天催交与回执 |
| 250223 还缺什么 / 覃祖悦还缺什么 | 按学号或名单姓名查这个人已交与还缺的类别 |
| 给某某写催交话术 | 用项目现有口径生成可直接粘贴的催交话术 |
| 有哪些待审的 | 列最新待审材料 |
| 谁还没交材料 | 报未交、需补交名单 |
| 打开服务留痕 | 切到对应页面并抬起主窗口 |
| 念一下 | 朗读上一句回答 |
| 你都能做什么 | 列能力与边界 |

### 它怎么连上 AI 与项目
- **不配 API 也能用**：本地规则直接命中上面八类（`source=local`），全程不联网。
- **配了 API**：只有本地规则没命中时，才把「你这句话 + 意图清单」发给模型，要它回一个意图和参数；名单、台账、材料内容一律不出本机，执行仍在本机跑。
- 缺项判断复用 `service.missing_categories`，话术复用 `service.chase_message` —— 和「台账」「名单核对」看到的是同一套口径，不会各说各话。

### 边界（写在代码里）
- 只读、只生成话术、只切页面；
- 不改台账、不改状态、不归档、不自动发消息；
- 说「把这份材料直接归档」「帮我把台账清空」，它按未知意图回，不动数据。

- 备选 `class-console-v0.29.0.exe`（20.9MB / 20,877,705 字节），单文件免解压。
- 便携包 SHA256 `B882B926765BBF0D8D280D9ECBC54F670D1B9E3043D4E8E5D1CD7945DB1D7091`；单文件 SHA256 `646E69E0DAEDFC163FE71E7A44138AD9B076CB104ACEEEAF45DF54FDB1EBD746`。

### 实测说明
本版未改启动路径。打包后跑了 3 次外部就绪：12.0 / 2.2 / 2.8 秒（首启 12.0 秒是新包被杀软全量扫描；当时机器刚跑完两轮 PyInstaller 打包）。样本只有 3 次、环境不同，**不作版本对比**；性能口径仍以 0.28.2 那批 12 次中位 721.0 / 1218.0ms 为准。

### 已知未做
- 代登记、代归档、批量改台账这类写操作没做——助手现在只读，需要写请走「提交材料」「材料台账」。
- 意图只覆盖上面八类；没命中的说法会明确回「还没接上」，不猜、不编学号和姓名。
