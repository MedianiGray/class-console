# v0.28.0 文件工具版 · 文件室里批量整理

桌面端这次把「文件批量处理」做成文件室的正式功能，不再靠外部小工具：**一个入口、三条路，全部先预览后执行**。

## 三条功能

**批量重命名**
- 前缀 / 后缀，支持 `{date}` `{name}` `{n}` 占位；
- 统一序号：起始、步长、位数（1–6 位）、位置（末尾 / 开头 / 只用序号）；
- 正则替换（只作用于去扩展名的主干）；
- 按文件名或修改时间排序；预览里逐条给出新名字。

**图片格式转换**
- JPEG / PNG / WEBP；质量三档（高 92 / 标准 88 / 紧凑 80，PNG 无损）；
- 结果写回同一目录；默认保留原件，先写新文件成功后才处理旧文件。

**按类别归位**
- 按台账类别把已登记文件移进「归档根 / 类别 /」；
- 台账里查不到的文件明确跳过，提示“先登记再归位”，不猜类别。

## 安全规则（写死在逻辑层）

- 只处理归档根内的文件，根外路径一律拒绝并写明原因；文件夹与索引 CSV 不参与改名和转换。
- 先预览、后执行：预览不落盘，执行前能看到每一条的去向与状态。
- 同名不覆盖：冲突自动加序号并在预览标注。
- 改名走两阶段（先临时名 `.ccrtmp` 再目标名），`a→b`、`b→a` 互换不会互相踩掉；改名可整体撤销。
- 改名与归位成功后同步台账 `arch` 路径并重写索引 CSV，台账不再指向旧路径。
- 每个动作写入操作日志（重命名 / 格式转换 / 按类别归位 / 撤销改名）。

文件列表改为多选（Ctrl / Shift），顶栏新增「批量工具」；没选中时对当前目录（或全库搜索结果）整批处理。权限沿用文件室的 `docs:archive`。
