## v0.27.0 静默版

这次主要解决桌面版启动慢、切页慢、台账一次渲染 5000 行的问题，网页端功能不变，只同步版本号与离线缓存。

### 桌面端

- 九个视图改为按需构建、按需导入，首屏只建工作台概览；切换视图不再重建全部页面。
- 刷新只刷当前页，待审数与日志总数改走 SQL 统计。
- 材料台账改为 300 条首屏 + “加载更多”，搜索、类别、类型、状态筛选后回到首屏，计数与筛选项一致。
- 台账查询支持状态、表单类型、分页；附件只查当前页。
- 启动阶段去掉重复刷新与日期格式首次编译开销。

### 性能实测（本机，5000 条材料）

| 项 | 结果 |
| --- | --- |
| 全部材料查询 | 59.1ms |
| 关键词 / 类别筛选 | 4.6ms / 13.7ms |
| 统计 / 日志查询 | 2.9ms / 21.7ms |
| 台账首屏 300 条刷新 | 15.6ms |
| 常驻内存 | 38.4MB |
| 源码冷启动（已有数据） | 中位 1.8s |
| 打包 EXE 冷启动（已有数据） | 空载中位 3.0s；负载复测 4.6s |

台账刷新是 300 条首屏 + 按需加载，不是一次性渲染 5000 行。冷启动瓶颈是 Tk 固定开销与单文件解包，不是数据库；v0.26 的打包冷启动约 10.6s，本次空载降到约 3.0s，但负载下复测约 4.6s，干净目录首次约 12.2s、二次约 4.8s，仍高于 1s 目标，按已知例外发布。

### 网页端

功能未变，版本号与离线缓存名同步为 `0.27.0` / `cc-web-v027-shell-v1`。PWA 更新链已验证：旧缓存会被清理，首次安装不弹更新提示，接管后弹出新版本提示。

### 安装

Windows 10/11 直接下载 `class-console-v0.27.0.exe`，双击运行，无需安装 Python。数据保存在本机 `%APPDATA%\ClassConsole`，不联网也能用。
