## 班级操作台 v0.28.2 · 语音朗读版

**一句话**：催交话术和材料详情现在可以直接听——用 Windows 自带中文语音读，不联网、不装第三方包、不改任何数据。

### 新增
- **服务留痕**底栏「朗读内容」：读"类型 + 学生 + 类别 + 完整话术"；再点一次停止，按钮自动复位；没选中记录时禁用。
- **材料台账**右栏「朗读」：读当前这份材料的基本信息、审批节点与最近操作（截前 800 字），未选中时禁用。
- `tts.py`：探测系统已装语音并优先中文（本机 Microsoft Huihui Desktop）；朗读跑在独立进程，随时可终止；找不到中文语音会直接说明原因，不拿英文语音硬念中文。

### 边界（写在代码里，不是口号）
- **只读**：不改台账、不写日志、不发消息。
- **不自动播报**：必须点按钮才出声。
- **离线**：文本只经本地临时文件传给系统语音，不出本机——所以明确不接 gTTS（它要把文本传到 Google）。

### 关于你发来的 TTS 十个库
新增 [`docs/外部能力接入台账.md`](docs/外部能力接入台账.md)，逐条给结论：

- **编入待接**（位置定好、等 GPU / API 前置）：CosyVoice 2、GPT-SoVITS、ChatTTS、Qwen3-TTS、Confucius4-TTS。
- **候补兜底**：Piper（+60MB 单音色，无中文语音包的机器可兜底）、Kokoro-82M（中文弱）、eSpeak NG（机械音）。
- **不引**：pyttsx3（只是再包一层 SAPI）。
- **不接**：gTTS（要上传文本）。

### 测试
- `tests/selftest.py` 50 组通过（新增第 50 组：探测口径、空文本拒绝、非朗读态）。
- `tests/gui_smoke.py` 26 段全绿（新增朗读入口断言，测试不发声）。
- 实机朗读自检通过，`stop()` 可中断。

### 安装
- 推荐 `class-console-v0.28.2-portable.zip`（21.2MB，36 个文件），解压一次即用。
- 备选 `class-console-v0.28.2.exe`（20.9MB），单文件免解压。
- 数据契约未变，0.28.1 的本机库与备份可直接沿用。

### 实测
便携包同机 12 次：窗口 0.66–0.91 秒（中位 0.72 秒）、当前页 1.11–1.51 秒（中位 1.22 秒）；其中 1 次 4.9 秒是新包首次被杀软全量扫描，单列不计入中位。
