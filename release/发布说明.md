# 发布与分发说明

## 产物分发方式

- **可执行程序（exe）** 不纳入 Git 仓库（二进制体积大、不便于 diff 维护），通过 GitHub
  **Release 附件**分发：每个版本在 Releases 页面上传 `班级操作台.exe`，供 Windows 用户直接下载运行。
- **源代码** 通过仓库主干分发，任何人可按本文档从源码自行运行或打包。

## 从源码打包 exe（Windows）

前置：Windows 系统 + Python 3（安装时勾选 tcl/tk，标准库自带 Tkinter）。

```bat
:: 安装打包工具
py -3.14 -m pip install "pyinstaller>=6.0"

:: 在仓库根目录执行单文件窗口版打包
py -3.14 -m PyInstaller --noconfirm --onefile --windowed --name "班级操作台" main.py
```

产物位于 `dist\班级操作台.exe`，双击即可独立运行；打包必须在 Windows 上进行，不能跨平台编译 Windows exe。

## 版本号规则

语义化版本 `MAJOR.MINOR.PATCH`（见 `version.py`）：

- MAJOR：不兼容改动（换框架、改数据结构导致旧备份无法读取）。
- MINOR：向后兼容的新功能或体验改进。
- PATCH：向后兼容的缺陷修复与稳定性加固。

每次发布需同步更新：`version.py` 的版本号与发布说明、`CHANGELOG.md` 对应条目。
