# 发布与分发说明

## 产物分发方式

- **可执行程序（exe/zip）** 不纳入 Git 仓库（二进制体积大、不便于 diff 维护），通过 GitHub
  **Release 附件**分发：每个版本上传单文件 `class-console-v<版本>.exe` 与便携目录包
  `class-console-v<版本>-portable.zip`。单文件由 `build_exe.bat` 产出，便携包由
  `build_portable.bat` 产出，二者都从 `version.py` 读取版本号。
- **源代码** 通过仓库主干分发，任何人可按本文档从源码自行运行或打包。

## 安装与首启口径

面向使用者的完整说明见 `docs/安装与首启说明.md`，发布前必须逐条核对：

- 附件名、窗口标题、README、发布说明四处版本一致；两个附件都附 SHA256 与字节数。
- 说明写清 Windows 10/11 64 位、无需 Python、SmartScreen「更多信息 → 仍要运行」、不承诺绕过管控。
- 首启写清便携版解压一次、加载页约 0.6 秒、同机已有数据窗口约 0.72 秒、当前页约 1.22 秒（12 次中位口径，其中 1 次 4.9 秒为新包首次被杀软扫描）、干净目录首次约 2.5 秒；单文件版约 2–3 秒；以及首次建库、三步上手、岗位切换与备份导出。
- 数据位置写清 `%APPDATA%\ClassConsole`；网页 localStorage 与桌面库互不同步。
- 换机用备份 JSON；归档原件另走交接包；明确禁止运行中复制数据库。
- 更新为覆盖便携目录或替换 exe，卸载为删程序目录/exe + 可选删数据目录；不写注册表、不装服务。
- 性能口径写清：加载页约 0.6 秒，主窗口中位约 0.72 秒、内容就绪中位约 1.22 秒（v0.28.2 便携 12 次口径），并注明其中 1 次 4.9 秒为新包首次被杀软扫描；台账首屏 300 条按需加载，不是一次性 5000 行；不把 1 秒目标写成"全部达成"。

## 从源码打包 exe（Windows）

前置：Windows 系统 + Python 3（安装时勾选 tcl/tk，标准库自带 Tkinter）；图片 / PDF 预览需 Pillow。

```bat
:: 安装运行与打包依赖
py -3.14 -m pip install "Pillow>=10.0" "pyinstaller>=6.0"

:: 在仓库根目录执行；视图懒加载，必须带 hidden-import
build_portable.bat   :: 推荐：dist\class-console-v<版本>-portable.zip
build_exe.bat        :: 单文件备选：dist\class-console-v<版本>.exe
```

两个脚本只是 ASCII 包装，实际逻辑在 `tools\build_portable.py` 与 `tools\build_onefile.py`，避开 `chcp 65001` 读取中文批处理时的截断问题。两者都内置 17 个 `ui_*` hidden-import；漏掉会出现程序能开、切页报缺模块且没有 Pillow。便携包是 onedir 目录 + zip，解压一次后启动不再解包；单文件每次启动都要解包。打包必须在 Windows 上进行，不能跨平台编译 Windows exe。

## 版本号规则

语义化版本 `MAJOR.MINOR.PATCH`（见 `version.py`）：

- MAJOR：不兼容改动（换框架、改数据结构导致旧备份无法读取）。
- MINOR：向后兼容的新功能或体验改进。
- PATCH：向后兼容的缺陷修复与稳定性加固。

每次发布需同步更新：`version.py` 的版本号与发布说明、`CHANGELOG.md` 对应条目。
