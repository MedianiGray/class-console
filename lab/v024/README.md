# v0.24 Bento 借鉴版（实验）

正式工作台 `web/index.html` 已并入 v0.24.0（Bento 首屏 + PWA）；本目录保留为概念来源与对照副本，数据与正式版各自独立。

## 这轮借鉴了什么

- **Bento 首屏**：把原来一条条纵向堆叠的看板改成 12 列网格；下一步、当前指标、待审队列、近期动态、类别分布、常用入口、本地处理器各占一格。
- **PWA 壳**：`manifest.json` + `sw.js` + 192/512 图标；断网重载后仍能打开工作台，数据继续走 localStorage。
- **性能克制**：没有引入 React/Next/Astro，也没有新增运行时依赖；页面仍是单文件 + 两个静态资源。
- **无障碍保留**：现有键盘焦点、`aria-label`、KPI 的 Enter/Space 触发全部保留；新增卡片不抢焦点。
- **本地处理器入口**：右下角卡片真实链接到 `../unkernel/unkernel-本地引擎验证台.html`，不在首屏加载 11.26 MB 内核。

## 没有照搬什么

- **Next.js 15 + Supabase**：会重新引入账号、云数据库和云同步，与你先前明确的“本地优先、不上账号”冲突；这版仍保持 GitHub Pages 可托管的静态单文件。
- **远程控制/屏幕墙/群控**：授权、隐私、网络边界都不是班级工作台该背的；要做也只能另立独立工具。
- **游戏发行平台**：与班级材料主流程无关，只适合归档成资料页。
- **“大肥鱼”式自动搬文件**：自动移动用户文件风险太高；桌面端现有 `drop_target.py` 只做“拖入登记”，保留人工确认。

## 实测

- 本机 Edge 158 headless，1440×1100：
  - 7 张 Bento 卡；无横向溢出；页面高 1382px。
  - 切到台账再回看板，7 行表格正常，无异常。
  - `manifest.json` 可读，Service Worker 注册 1 个；断网重载后标题、Bento、当前视图都在。
  - 浅色、深色均通过；390px 窄屏单列堆叠，无横向溢出。
- 数据为首次运行的示例数据，页面已标“示例数据，不计入上手进度”。

## 运行

在仓库根目录起静态服务（示例）：

```powershell
python -m http.server 8781 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8781/lab/v024/`。
