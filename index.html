班委 · 教师

开始使用

三步收第一份材料

桌面 v0.30.1

学生用网页，班委和教师用桌面版；数据各自留在本机，需要搬运时用备份或交接包。

1

打开或下载

学生直接进在线版；班委 / 教师下载便携包，解压一次，双击“班级操作台.exe”。

2

导入名单、选模板

录入学号—姓名，选班会 / 走访 / 承诺 / 约谈模板；没有模板就自定义。

3

收第一份材料，归档出证据包

提交或拖入文件 → 审核 → 归档 → 导出证据包；一条材料走完整条链。

Windows 64 位 · 离线可用

服务边界

先把“不伤害”写清楚

数据留在本机

桌面用 SQLite，网页用浏览器本地存储；不上传、不要账号，断网也能用。

AI 只给建议

查缺项、写草稿、做摘要；不改台账、不自动归档、不自动发消息。

不公开点名、不排名

催交说“这项还差你一份”，不贴“你怎么还没交”；免交、延期、回执留痕。

边界外：账号登录、多人实时、云端收集、自动群发、平台爬取。这些不在当前版本里假装能做。
