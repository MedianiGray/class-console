先看人，再看功能

学生、班委、老师，各自少做一步

一条材料，完整走完

不是把文件堆在网盘里，而是让一件事有始有终

提交只登记，审核才归档；每一步有人、有时间、有原因、有文件位置。

01

提交 / 收集

表单、文件夹、拖入文件，三种入口统一登记；先预览再入账。

02

审核

通过或驳回，驳回必须写原因；状态就地变化，留痕可回放。

03

归档

按“类别 / 学号-姓名 / 编号_材料名”落盘，写索引，重名不覆盖。

04

交差

证据包、交接包、汇总表；评审方不装软件也能看懂。

一条材料从选中到归档 ≤3 次点击；每天巡检待审、未交、逾期 ≤2 分钟。这是当前版本已经验收的硬尺。

不拿“未来功能”冒充现在可用；下面把已可用、建设中、边界外分开写。

材料台账编号、搜索、类别 / 类型 / 状态筛选，详情带模板栏目与流转时间线。

归档与证据归档索引、完整性检查、ZIP 证据包；脱离软件也能读懂目录与字段。
文件室与批量目录树、预览、缺失反查；批量改名、图片转换、按类别归位，先预览后执行。
AI 副驾查缺项、驳回草稿、归档命名、情况说明；只给建议，不改台账、不自动归档。
能力中心低频能力一页分组卡，按岗位显隐；入口只负责找到并打开，不绕开主流程。

现在开始

三步就能收第一份材料

学生用网页，班委和老师用桌面版；数据各自留在本机，需要搬运时用备份或交接包。

1

打开或下载

学生直接进在线版；班委 / 教师下载便携包，解压一次，双击 `班级操作台.exe`。

2

导入名单、选模板

录入学号—姓名，选班会 / 走访 / 承诺 / 约谈模板；没有模板就自定义。

3

收第一份材料，归档出证据包

提交或拖入文件 → 审核 → 归档 → 导出证据包；一条材料走完整条链。

服务边界

先把“不伤害”写清楚，再谈功能

工具替人记事，不替人评判；数据属于班级，不属于个人；服务在不需要时消失。

数据留在本机

桌面用 SQLite，网页用浏览器本地存储；不上传、不要账号，断网也能用。

AI 只给建议

查缺项、写草稿、做摘要；不改台账、不自动归档、不自动发消息，关键动作人点第二次。

不公开点名、不排名

催交说“这项还差你一份”，不贴“你怎么还没交”；免交、延期、回执都能留痕。

学生要装软件吗？

不用。打开在线版就能提交；桌面版是给班委 / 教师做收集、审核、归档和交差用的。

能多人同时用吗？

当前不能。桌面与网页各自本机存储；换届或换机用备份、交接包搬运。多人实时要后端，单独立项。

专业功能什么时候有？

按路线逐版接入：项目底座 → 音频转码 → 文档工具 → 赛事 / 产品模板。未上线的不在本页冒充可用。

数据丢了怎么办？

桌面有备份 / 恢复与恢复预览；网页可导出备份。换电脑前先导出，别只留在浏览器缓存里。
